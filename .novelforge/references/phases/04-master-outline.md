## 一、阶段概述

全局大纲是整部小说的"建筑蓝图"。它不需要细化到每一章，但必须回答三个根本问题：
1. **故事从哪里开始？**（起点状态）
2. **故事到哪里结束？**（终点状态）
3. **中间经历了哪些关键转折？**（结构节点）

**核心原则**：大纲是活的文档，允许在创作中调整细节，但主线方向和关键节点一旦确定，不轻易推翻。

## 三、情感曲线设计

### 3.1 什么是情感曲线？

情感曲线是读者在阅读过程中情感强度的变化轨迹。好的情感曲线应该像"锯齿波"——不断攀升，周期性释放，总体趋势向上。

```
情感强度
│
│          ╱╲        ╱╲╲       ╱╲
│        ╱    ╲    ╱    ╲╲   ╱  ╲   ← 小高潮越来越高
│      ╱      ╲╱╱      ╲╲╱    ╲
│    ╱                          ╲
│  ╱                            ╲  ← 大高潮后的收束
│╱                               ╲
└──────────────────────────────────── 章节
  第1卷      第2卷      第3卷     尾声
```

### 3.2 情感节点类型

| 节点类型 | 情感方向 | 频率 | 作用 | 示例 |
|---------|---------|------|------|------|
| 小爽点 | ↑ 上升 | 每3-5章 | 维持阅读动力 | 打脸装逼、获得宝物、突破境界 |
| 大爽点 | ⬆ 飙升 | 每10-15章 | 高潮释放 | 大战胜利、复仇成功、真相揭露 |
| 虐点 | ↓ 下降 | 适度使用 | 制造张力 | 同伴牺牲、被人背叛、实力受损 |
| 温情点 | → 平缓 | 紧张后 | 情感缓冲 | 日常互动、搞笑桥段、感情升温 |
| 悬念点 | ⤴ 悬停 | 每卷末 | 驱动翻页 | 重大伏笔揭露、新危机出现 |

### 3.3 爽点密度规划

**黄金公式**：
```
每3-5章 → 1个小爽点（打脸、突破、获宝）
每10-15章 → 1个大爽点（大战、反转、真相）
每1卷 → 1个超级爽点（弧段高潮）
全书 → 3-5个史诗爽点（改变格局的大事件）
```

**爽点升级原则**：
- 后面的爽点必须比前面的更爽
- 不能同类型连续使用（连续打脸3次就腻了）
- 爽点前必须有足够的"压力积累"（被欺负越惨，翻盘越爽）

## 五、不同类型的结构模式

### 5.1 玄幻/仙侠：地图推进型

```
结构特点：主角从小地图到大地图，逐步探索更广阔的世界
典型模式：家族 → 城市 → 王国 → 大陆 → 界面 → 宇宙

优势：天然的升级感和新鲜感
陷阱：容易写成"流水账"，每个地图都是重复套路
对策：每个地图都要有独特的核心冲突和不可替代的角色
```

### 5.2 都市：事件驱动型

```
结构特点：以一个个事件/案件/危机串联，主角在处理事件中成长
典型模式：日常 → 事件发生 → 调查/应对 → 解决 → 新日常

优势：节奏灵活，可以随时加入新元素
陷阱：容易松散，缺乏主线推动力
对策：用一条暗线贯穿所有表面独立的事件
```

### 5.3 言情：关系推进型

```
结构特点：以核心CP的关系变化推动叙事
典型模式：相遇 → 误会 → 相知 → 阻碍 → 分离 → 重逢 → 确认

优势：情感张力强，读者代入感强
陷阱：误会/阻碍设计不合理会让读者烦躁
对策：每个阻碍都必须是"合理的"，不是为了拖剧情而制造
```

### 5.4 科幻：谜题揭示型

```
结构特点：以世界的秘密/真相逐步揭露驱动叙事
典型模式：异常现象 → 初步探索 → 局部真相 → 颠覆认知 → 终极真相

优势：悬念感强，读者会追着看
陷阱：真相不够震撼会让读者失望
对策：真相的设计必须"超出读者预期但在逻辑之内"
```

### 5.5 无限流/游戏：副本循环型

```
结构特点：以一个个副本/任务/关卡组成，主角在其中成长
典型模式：进入副本 → 探索规则 → 危机 → 通关 → 结算/休息 → 新副本

优势：每个副本都是新鲜体验
陷阱：副本之间缺乏联系，读者疲劳
对策：副本之间要有暗线连接，主世界的剧情不能停
```

## 六、主线一致性检查

在大纲完成后，进行以下自检：

```
【全局大纲自检清单】
□ 主角的弧线是否完整？（从A状态到B状态，有清晰的变化）
□ 主线冲突是否贯穿全书？（不是中途换了一个完全不相干的主线）
□ 每个弧段是否都有独特的看点？（不是重复的套路）
□ 反派的布局是否合理？（不是最后突然冒出来的）
□ 伏笔是否都有回收计划？（不要挖坑不填）
□ 爽点密度是否合理？（不要连续10章没有爽点）
□ 结局是否能撑起全书的期待？（不能虎头蛇尾）
□ 全书规模是否可控？（和Phase 1计划的字数是否匹配）
```
