# 伏笔追踪器

> 伏笔是网文的灵魂。埋下的每一条伏笔都是对读者的承诺——不兑现就是失信。本文档提供完整的伏笔管理系统。

---

## 一、伏笔分类

### 按重要程度

| 类别 | 说明 | 回收周期 | 示例 |
|------|------|----------|------|
| S级·主线伏笔 | 关乎全书核心谜团 | 可跨全书 | 主角身世之谜、最终Boss的真实身份 |
| A级·支线伏笔 | 重要支线的关键线索 | 30-80章内回收 | 神秘组织的真实目的、某宝物的隐藏功能 |
| B级·角色伏笔 | 与角色成长/关系相关 | 15-40章内回收 | 配角的隐藏身份、感情线暗示 |
| C级·氛围伏笔 | 营造世界观深度 | 10-25章内回收 | 某地的异常现象、路人的神秘暗语 |
| D级·红鲱鱼 | 故意误导读者 | 在真相揭晓时澄清 | 故意指向错误嫌疑人的线索 |

### 按内容类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 物品伏笔 | 某个看似普通的物品后来有大用 | 街边买的破铜镜是上古神器碎片 |
| 人物伏笔 | 某人的真实身份/能力尚未揭露 | 扫地老头其实是隐世强者 |
| 事件伏笔 | 某个事件背后有更深层原因 | 村庄灭门案与主角身世有关 |
| 台词伏笔 | 某句看似随意的话暗含关键信息 | "你的眼睛，和她一模一样" |
| 世界观伏笔 | 世界运行规则中隐藏的秘密 | 为什么修士超过千岁必定陨落？ |

## 二、伏笔生命周期

```
🟡 埋设中 → 🔵 发酵中 → 🟢 已回收 → ⚪ 已放弃
```

### 各阶段定义

| 阶段 | 状态 | 说明 |
|------|------|------|
| 🟡 埋设中 | 刚刚植入，首次提及 | 读者可能注意到也可能忽略 |
| 🔵 发酵中 | 后续章节有再次提及/暗示 | 加深读者印象，制造期待 |
| 🟢 已回收 | 真相揭晓，伏笔兑现 | 给读者"原来如此"的满足感 |
| ⚪ 已放弃 | 因剧情调整放弃该伏笔 | 需确保放弃不影响已发布内容 |

### 发酵技巧
- 第一次提及：轻描淡写，不引起特别注意
- 第二次提及（间隔5-10章）：稍加强调，让细心读者注意到
- 第三次提及（临近回收）：制造紧迫感，读者开始期待
- 回收时：明确呼应前文，让读者有恍然大悟的快感

## 四、超期提醒规则

### 默认超期标准

| 伏笔等级 | 最长无提及间隔 | 最长回收期限 |
|----------|---------------|-------------|
| S级 | 30章 | 不限（但需定期发酵） |
| A级 | 20章 | 80章 |
| B级 | 15章 | 40章 |
| C级 | 10章 | 25章 |
| D级 | — | 真相揭晓前 |

### 超期处理流程

1. **黄色预警**：超过最长无提及间隔的70%
   - 行动：在近期章节中安排一次暗示/提及

2. **橙色预警**：超过最长无提及间隔
   - 行动：立即在下一章安排回顾或推进

3. **红色预警**：超过最长回收期限
   - 行动：必须在3章内回收，或标记为放弃并处理善后

### 自动检查脚本逻辑
```
每次写新章节前：
  遍历所有状态为 🟡 或 🔵 的伏笔：
    计算 = 当前章节号 - 最后提及章节号
    如果 计算 > 对应等级的提醒阈值：
      输出预警："伏笔F00X已经{计算}章未被提及，请在近期章节安排回顾"
```

## 五、回收质量评估

### 评估维度

| 维度 | 满分标准 | 扣分情况 |
|------|----------|----------|
| 呼应度 | 明确呼应埋设时的内容 | 回收时读者想不起来曾经埋过 |
| 惊喜度 | 真相出人意料但合情合理 | 读者早就猜到 / 太牵强 |
| 满足度 | 读者有"恍然大悟"的快感 | 回收草率，一笔带过 |
| 影响力 | 回收推动了剧情重大转折 | 回收了但对剧情没影响 |
| 铺垫充分度 | 回头看伏笔线索链完整 | 只埋了一次就回收，缺乏铺垫 |

### 评分标准
- ⭐⭐⭐⭐⭐ 完美回收：惊喜+满足+推动剧情，读者拍案叫绝
- ⭐⭐⭐⭐ 优秀回收：呼应到位，有适度惊喜
- ⭐⭐⭐ 及格回收：完成了回收，但缺乏惊喜
- ⭐⭐ 勉强回收：草草了事，读者无感
- ⭐ 失败回收：强行回收，逻辑牵强，不如不收

## 六、AI写作专用规则

### 每章生成前必做
1. 读取伏笔追踪表
2. 检查是否有即将超期的伏笔
3. 检查本章是否会与已有伏笔矛盾
4. 如果本章涉及回收伏笔，确认与埋设时的内容一致

### 严禁事项
- ❌ 不查追踪表就写涉及伏笔的内容
- ❌ 回收伏笔时凭"记忆"而非查阅原文
- ❌ 修改已埋设伏笔的内容（已发布的章节不可变）
- ❌ 忘记更新追踪表的状态

### 新增伏笔流程
1. 在章节中自然地植入伏笔
2. 立即在追踪表中新增记录
3. 规划后续暗示和回收的大致时间点
4. 检查新伏笔是否与已有伏笔冲突

> 💡 **黄金法则**：埋1条伏笔时，至少要想好它如何回收。不知道怎么收的伏笔，不要埋。
