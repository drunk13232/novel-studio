# Contributing to NovelForge AI

Thank you for your interest in contributing! 🎉

## How to Contribute

### 🐛 Bug Reports

If you find issues with templates, instructions, or quality gates:

1. Open an issue on GitHub
2. Describe the problem clearly
3. Include which file(s) are affected
4. Suggest a fix if you have one

### 📝 New Genre Guides

We welcome guides for genres not yet covered:

- 🗡️ Wuxia (武侠)
- 🎮 Gaming / LitRPG (游戏)
- 📜 Historical (历史)
- 👻 Horror (恐怖/灵异)
- 🕵️ Mystery (悬疑/推理)
- 🎭 Fanfiction (同人)

**Format**: Follow the structure of existing guides in `references/genre-guides/`. Each guide should include:
- 题材特征 (Genre characteristics)
- 经典套路 (Classic patterns)
- 核心爽点 (Core satisfaction points)
- 节奏特点 (Pacing characteristics)
- 世界观设计建议 (Worldbuilding suggestions)
- 常见坑点及避免方法 (Common pitfalls)
- 代表作品参考 (Reference works)

### 🌍 Translations

Help translate the framework to other languages:
- Japanese (日本語)
- Korean (한국어)
- English (for Western fiction genres)

### 🔧 Agent Adapters

Add support for more AI coding agents:
- Windsurf
- Aider
- Continue.dev
- Other agents

### 💡 Improvements

- Better prompt engineering for specific phases
- New quality check dimensions
- Refined anti-AI-pattern lists
- Better templates

## Submission Process

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/new-genre-guide`)
3. Make your changes
4. Test with at least one AI agent
5. Submit a Pull Request

## Code of Conduct

- Be respectful and constructive
- Focus on helping creators write better novels
- Keep content appropriate and professional

Thank you for making NovelForge AI better! 🙏
