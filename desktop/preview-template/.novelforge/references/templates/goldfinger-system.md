# 金手指 / 外挂系统设定模板

在网文创作中，金手指（Cheat/Goldfinger）是核心驱动力。如果金手指设计失衡，小说后期必然面临战力崩坏。请在项目初期（Phase 2）严格填写此表。

## 1. 基础设定
- **外挂名称**：[例如：深蓝加点面板 / 诡异模拟器 / 随身老奶奶]
- **外挂类型**：[例如：数据面板类 / 资源获取类 / 信息全知类 / 时间重置类]
- **外挂载体**：[例如：脑海中的 UI / 脖子上的玉佩 / 右手的一道疤]
- **绑定条件**：[主角是如何获得它的？获得时是否经历了生死考验？]

## 2. 核心功能与成长线
- **初级阶段（第 1-50 章）**：
  - *具体功能*：[在此阶段能做到什么。例如：每天可模拟1次未来，最长模拟3天]
- **中级阶段（第 51-200 章）**：
  - *升级条件*：[如何从初级升到中级？例如：吸收大量高阶灵石]
  - *具体功能*：[例如：每天可模拟3次，并带出1件模拟器中的物品]
- **高级阶段（后期）**：
  - *升级条件*：[例如：斩杀此界天道]
  - *具体功能*：[最终形态，例如：跨界模拟，时间长河漫游]

## 3. ⚠️ 限制与代价（防崩塌核心）
> *没有代价的力量会导致叙事张力彻底消失。请务必设定以下限制！*

- **资源消耗**：[每次使用需要消耗什么？必须是主角难以轻易获取的东西]
- **冷却时间 (CD)**：[用完一次要等多久？]
- **使用副作用**：[对主角自身的损伤。例如：折寿、剧痛、理智降低]
- **绝对禁区（外挂做不到的事）**：
  - 1. [例如：无法直接提升境界，只能提升熟练度]
  - 2. [例如：无法凭空造物，必须符合等价交换]
  - 3. [例如：无法干涉高于自己两个大境界的敌人]

## 4. 与世界的交互
- **暴露风险**：如果被别人发现了外挂的存在，会发生什么？主角采取了什么伪装措施？
- **世界观相容性**：这个外挂的存在是否符合当前世界的底层逻辑？（比如修仙界出现赛博面板，其本质可能是上古大能的遗留法宝）

*注：AI 在执行 Phase 4 和 Phase 6 时，必须核对本表中的“限制与代价”，禁止让主角无限制、无代价地开挂。*
