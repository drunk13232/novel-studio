# 反派降智自检表 (Villain IQ Check)

大模型（LLM）极容易写出“为了被主角打脸而无脑送人头”的弱智反派。这会严重拉低小说的整体智商感。在 Phase 8（质量审查）时，质检员必须对出场的反派进行逻辑诊断。

---

## 🧐 诊断维度

### 1. 核心利益测试 (Motivation Check)
- **问题**：反派去招惹主角，是为了获得什么实质性的利益（夺宝、争夺修炼资源、政治站队）？
- **降智雷区**：反派纯粹因为“看主角不顺眼”、“觉得主角太嚣张”而大动干戈，甚至不惜搭上整个家族的性命。
- **合格标准**：反派的每一次行动，都应该符合他《角色卡》中的“核心动机”和“自身利益最大化”。

### 2. 战力评估测试 (Risk Assessment Check)
- **问题**：反派在对付主角前，是否进行了背景调查和实力评估？
- **降智雷区**：明明主角昨天才当众斩杀了元婴期修士，今天反派（一个金丹期）还要跑去主角面前嘲讽。
- **合格标准**：反派必须懂得敬畏强者。反派的错误行动必须是基于“信息差”。

### 3. “葫芦娃救爷爷”测试 (Escalation Check)
- **问题**：反派势力是否是一波接一波地派比主角等级稍微高一点的杂兵去送经验？
- **降智雷区**：反派少爷被打死 -> 派几个家丁 -> 家丁被打死 -> 派管家 -> 管家被打死 -> 派长老。
- **合格标准**：真正的聪明的反派，一旦发现主角具备威胁，应该直接雷霆一击，派最高端战力彻底扼杀（主角逃脱是因为底牌、第三方势力介入或运气，而不是因为反派手下留情）。

### 4. 情绪控制测试 (Emotional Control Check)
- **问题**：反派在被打脸时，第一反应是什么？
- **降智雷区**：反派在拍卖会上被主角抢了风头，立刻在众目睽睽之下暴跳如雷，大喊“你给我等着！”
- **合格标准**：反派（尤其是活了几百年的老怪、位高权重的总裁）应该懂得喜怒不形于色，表面笑嘻嘻，暗地里下死手。

---

## 🛠️ 纠偏手段 (Phase 10 修订指南)

如果在正文生成中触发了上述“降智雷区”，请在 Phase 10 执行以下修复策略：

1. **补齐信息差**：加入一句话，说明反派为何误判了形势（“探子回报说那剑修已经重伤濒死，李长老这才放心追击……”）。
2. **替换行动动机**：将“嫉妒主角的帅气”改为“主角手中的剑，正是李家寻找了百年的传承秘钥”。
3. **增加第三方压力**：反派去招惹主角，是因为他被更强大的上司逼迫，不得不这么做。
4. **保留反派底线**：在反派被打败前，至少展现一次符合他身份的智谋或决断力。
