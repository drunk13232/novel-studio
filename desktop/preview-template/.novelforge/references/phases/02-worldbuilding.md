## 一、阶段概述

世界观是网络小说的地基。一个精心设计的世界观不仅让故事可信，更能源源不断地产生新的矛盾和情节。本阶段的核心任务是：**把"世界观"从模糊的感觉变成明确的规则文档**。

**关键理念**：好的世界观不是"什么都能发生"，而是"明确规定了什么不能发生"。限制产生戏剧性。

## 二、力量体系设计（修炼/能力系统）

### 2.1 境界划分模板

力量体系是网文（尤其是玄幻/仙侠类）的核心骨架。设计时需遵循以下原则：

**设计原则**：
- **层级清晰**：每个境界有明确的能力上限和标志性能力
- **进阶有据**：升级不是"突然顿悟"，需要明确条件
- **对照可查**：不同境界的战力差距有清晰对照

```
【力量体系设计卡】

一、境界总览
┌─────────┬──────────┬──────────────┬───────────┐
│ 境界名称 │ 对应层级 │ 标志性能力    │ 寿命上限   │
├─────────┼──────────┼──────────────┼───────────┤
│ 炼气期   │ 凡人之巅  │ 引气入体      │ 150年     │
│ 筑基期   │ 初入修行  │ 御物飞行      │ 300年     │
│ 金丹期   │ 小有所成  │ 神识外放      │ 800年     │
│ 元婴期   │ 一方强者  │ 元婴出窍      │ 2000年    │
│ 化神期   │ 顶尖大能  │ 领域展开      │ 5000年    │
│ 渡劫期   │ 半步超脱  │ 天劫对抗      │ 10000年   │
│ 大乘期   │ 超脱凡俗  │ 空间穿梭      │ 无限      │
└─────────┴──────────┴──────────────┴───────────┘

二、进阶规则
- 炼气→筑基：需收集三种天材地宝 + 72小时不间断冲关
- 筑基→金丹：需领悟本命法则 + 通过心魔试炼
- ...（每个进阶都要有明确条件）

三、战力对照
- 金丹期一击 ≈ 现代一枚导弹的威力
- 元婴期可单挑一座城市的常规军事力量
- 化神期可影响天气和地形
```

### 2.2 非修仙类力量体系参考

| 类型 | 力量来源 | 等级划分示例 | 设计重点 |
|------|---------|------------|---------|
| 都市异能 | 基因变异/觉醒 | E→D→C→B→A→S→SS→SSS | 能力克制关系 |
| 科幻机甲 | 科技等级 | T1→T5 | 资源与技术限制 |
| 游戏系统 | 系统赋予 | Lv1→Lv100 + 转职 | 数值平衡与成长曲线 |
| 末日生存 | 丧尸病毒/辐射 | 普通人→觉醒者→进化者 | 代价与风险 |
| 无力量体系 | 权谋/商战/情感 | 社会地位/财富/人脉 | 资源博弈与人心较量 |

### 2.3 力量体系的"硬限制"设计

这是**反幻觉机制**的关键部分。必须明确：

```markdown
## ⛔ 绝对禁止（硬限制）
1. 低境界绝对不可能击败高两个大境界的对手（除非使用一次性禁忌手段且付出巨大代价）
2. 境界不可逆退（除非遭遇特定诅咒，且必须有前因铺垫）
3. 不存在"无限恢复"——任何恢复都需要时间和资源

## ⚠️ 有条件允许（软限制）
1. 越级战斗：允许越一个小境界，但必须利用环境/装备/特殊能力
2. 禁忌手段：可以使用，但必须付出对等代价（寿命/修为/身体）
3. 外挂辅助：金手指可以加速修炼，但不能跳过关键瓶颈
```

## 五、契约系统（rules.md）——反幻觉核心

### 5.1 什么是设定契约？

`rules.md` 是整个项目的 **不可违反的硬性法律**。它记录了世界观中绝对不能被打破的规则。AI 在后续所有阶段（尤其是 Phase 7 正文生成和 Phase 8 质量审查）中，必须 **首先检查 rules.md** 再进行创作。

### 5.2 rules.md 结构模板

```markdown
# 📜 设定契约 (Rules.md)

> ⚠️ 以下规则具有最高优先级。任何创作内容违反以下规则，
> 质检阶段将标记为🔴致命错误，必须修改。

## 一、力量规则
1. 炼气期修士不可能飞行
2. 金丹期以下不可使用神识
3. 跨两个大境界的战斗差距不可逾越
4. ...

## 二、世界规则
1. 凡人不知道修仙界的存在（在xx卷之前）
2. 传送阵只能传送到已标记的固定位置
3. 灵石是唯一通用货币，不可无中生有
4. ...

## 三、死亡规则
1. 重要角色死亡不可复活（除非提前铺垫了特定复活手段）
2. 元婴期以上强者陨落会引发天象异变
3. ...

## 四、金手指规则
1. 主角的xx能力每天只能使用3次
2. 使用金手指有明确代价：xxx
3. 金手指不能解决所有问题，以下情况无效：xxx
4. ...
```

### 5.3 契约维护机制

- **新增规则**：当后续创作中发现新的隐含规则时，追加到 rules.md
- **修改规则**：需要标注修改原因和影响的章节范围
- **违反处理**：Phase 8 质检时，任何违反 rules.md 的内容自动标记为🔴，必须修改
