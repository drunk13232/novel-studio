# Phase 1: 灵感捕捉 & 题材定位

> **阶段编号**: Phase 1 / 10
> **执行角色**: 🌍 世界观建筑师
> **触发条件**: `/novel-new` 或 用户表达"想写新书"意图
> **阶段目标**: 从模糊灵感中提炼可执行的创作方向，完成市场定位与核心卖点锁定
> **输出产物**: `project.json` + `题材定位报告`

---

## 一、阶段概述

灵感捕捉是整个创作流水线的起点。多数作者的失败始于"想到什么写什么"——没有经过系统化的题材定位，就直接动笔。本阶段通过结构化访谈 + 市场分析，将模糊的创作冲动转化为清晰的项目蓝图。

**核心原则**：不急于动笔，先回答"写什么"和"为谁写"。

---

## 二、结构化访谈问卷（8-10题深度访谈）

AI 应以 **对话式** 逐题引导用户，而非一次性抛出所有问题。每题可追问1-2个细化问题。

### 第一组：核心方向（必问）

**Q1：你脑海中的故事是什么样的？**
- 引导用户用 2-3 句话描述核心创意
- 追问："如果用一句话向朋友推荐这本书，你会怎么说？"
- 目的：提取 **一句话核心卖点（Logline）**

**Q2：这个故事属于什么类型/流派？**
- 提供选项参考：玄幻、仙侠、都市、言情、科幻、历史、悬疑、游戏、末日、无限流……
- 追问："有没有混合类型？比如'都市+修仙'或'科幻+末日'？"
- 追问："你心目中最接近的已有作品是哪部？"
- 目的：锁定 **主类型 + 副类型**

**Q3：你的目标读者是谁？**
- 年龄段：学生群体 / 上班族 / 全年龄
- 性别倾向：男频 / 女频 / 通吃
- 阅读偏好：爽文快餐 / 有深度的慢热 / 轻松搞笑
- 目的：确定 **读者画像** 与 **阅读期待**

### 第二组：风格定位（必问）

**Q4：你希望这本书的整体基调是什么？**
- 提供参考轴：
  - 热血燃 ←→ 阴暗致郁
  - 轻松幽默 ←→ 严肃沉重
  - 爽快直给 ←→ 伏笔悬疑
  - 单线叙事 ←→ 群像史诗
- 目的：确定 **叙事基调矩阵**

**Q5：有没有你特别喜欢的参考作品？（1-3部）**
- 可以是网文、实体小说、影视、动漫、游戏
- 追问："你喜欢它的哪个方面？剧情？人设？世界观？文笔？节奏？"
- 目的：提取 **风格参照锚点**

### 第三组：规模规划（必问）

**Q6：你计划写多长？**
- 短篇试水：10-30万字（50-100章）
- 中篇标准：50-100万字（200-400章）
- 长篇大作：100-300万字（400-1000章）
- 追问："你预计能坚持日更吗？每天大概能写多少字？"
- 目的：确定 **体量级别** 与 **可行性评估**

**Q7：你打算在哪个平台发布？**
- 起点中文网 / 番茄小说 / 刺猬猫 / 晋江 / 七猫 / 知乎 / 多平台
- 追问："是否考虑签约？对收入有期待吗？"
- 目的：确定 **平台适配策略**（不同平台有不同的读者口味和字数偏好）

### 第四组：创意细化（选问，视情况追问）

**Q8：你最想在这本书里实现什么？**
- 一个炸裂的反转？一段刻骨铭心的感情？一个震撼的世界观？纯粹的爽感？
- 目的：确定 **核心情感卖点**

**Q9：你最不想写成什么样？**
- "不想太套路" / "不想太慢热" / "不想太小白" / "不想太黑暗"
- 目的：设定 **创作红线**（后续流水线将持续检查）

**Q10：你有没有已经想好的角色或场景？**
- 如果有，记录下来作为后续阶段的种子素材
- 目的：捕捉 **灵感碎片**，避免遗漏

## 三、市场分析框架

### 3.1 竞品分析模板

在确定类型后，AI 应辅助用户分析同类型头部作品：

```
【竞品分析卡】
├─ 作品名称：《xxx》
├─ 平台/成绩：起点中文网 / 均订 xx万 / 总收藏 xx万
├─ 核心卖点：一句话总结
├─ 开局方式：（穿越/重生/天降/日常开局...）
├─ 节奏特点：（快节奏爽文 / 慢热铺垫 / 起伏交替）
├─ 人设特点：（主角性格、金手指类型）
├─ 读者评价关键词：（从评论区提取高频词）
└─ 可借鉴/需规避：
    ✅ 可借鉴：xxx
    ⚠️ 需规避：xxx
```

### 3.2 平台策略对照表

| 平台 | 主力读者 | 偏好类型 | 章均字数 | 黄金三章要求 | 关键成功要素 |
|------|---------|---------|---------|------------|------------|
| 起点中文网 | 男性为主，老白兼有 | 玄幻、都市、科幻 | 2000-3000字 | 极其重要 | 金手指明确、节奏快 |
| 番茄小说 | 下沉市场、碎片阅读 | 赘婿、神医、战神 | 1500-2000字 | 开篇30秒定生死 | 极致爽感、短章快翻 |
| 刺猬猫 | 二次元、轻小说 | 同人、轻小说风 | 2000-4000字 | 重要 | 人设鲜明、梗文化 |
| 晋江 | 女性为主 | 言情、耽美、百合 | 3000-5000字 | 重要 | 感情线、人设魅力 |
| 知乎 | 高学历读者 | 悬疑、脑洞、现实 | 3000-5000字 | 中等 | 文笔质量、逻辑性 |

### 3.3 类型热度与蓝海分析

AI 应基于已知信息，帮助用户判断：
- **红海赛道**：竞争激烈但读者基数大（如：系统流玄幻）
- **蓝海赛道**：竞争较少但可能读者也少（如：硬科幻末日）
- **差异化切入点**：在红海中找蓝海（如：系统流 + 美食主题 = 差异化）

## 四、核心卖点提炼方法论

### 4.1 "三问定位法"

1. **这本书和别的书有什么不同？** → 差异化卖点
2. **读者读了之后会获得什么体验？** → 情感卖点
3. **用一句话让人想看？** → 钩子卖点

### 4.2 卖点公式

```
核心卖点 = [独特设定/金手指] + [核心冲突] + [情感钩子]

示例：
- "重生回到高考前一天的学霸，带着未来十年的记忆改写人生"
- "修仙界最弱的炼气期修士，却拥有能看透一切的天眼"
- "被全家族抛弃的废柴少女，觉醒了万年一遇的双生武魂"
```

### 5.2 题材定位报告

完成访谈后，AI 应生成一份结构化的定位报告，包含：

```markdown
# 题材定位报告

## 一、项目概览
- 暂定书名 / Logline / 类型定位

## 二、市场分析
- 所选赛道竞争态势
- 对标作品分析
- 差异化策略

## 三、核心卖点
- 三大卖点提炼
- 目标读者画像

## 四、风险提示
- 该题材的常见坑
- 建议规避的方向

## 五、下一步行动
- 建议进入 Phase 2: 世界观构建
- 重点构建方向建议
```

**模板参考**：填写 `references/templates/project-init.md` 中的模板

### 5.3 书名与简介生成

在 project.json 中的 logline 确认后，AI 应辅助用户生成：

**书名候选（至少 3 个）**：
- 类型 A：直白型（直接点明核心卖点，如《修仙模拟器》《全球高武》）
- 类型 B：悬念型（引发好奇心，如《诡秘之主》《大奉打更人》）  
- 类型 C：人设型（突出主角特质，如《赘婿》《神医凰后》）

**书名黄金法则**：
- 2-6 个字为宜（太长记不住，太短没信息）
- 包含关键词（方便平台搜索推荐）
- 避免与热门作品撞名

**作品简介模板**（起点标准 3-5 行）：
```
第一行：悬念钩子（抛出最大的矛盾/反差/金手指）
第二行：主角困境（他面临什么不可能完成的任务）
第三行：核心爽点预告（暗示读者能获得什么阅读体验）
第四行（可选）：世界观一句话速写
第五行（可选）：风格标签（如：轻松 | 热血 | 无敌流）
```

**输出产物**：书名定稿 + 作品简介定稿，追加到 project.json 中
