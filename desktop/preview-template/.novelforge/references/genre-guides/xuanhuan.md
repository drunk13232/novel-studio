# 玄幻/修仙 题材指南

> 玄幻修仙是网文最大的品类，读者基数庞大但竞争也最激烈。本指南覆盖从设定搭建到平台策略的全流程。

---

## 一、题材核心特征

### 修炼体系
玄幻修仙的根基是一套让人"想修炼"的力量体系。好的体系需要：
- **可量化**：读者能清楚知道主角在什么位置，离下一步有多远
- **有层级**：境界之间有明确的差距和壁垒
- **有规则**：突破需要条件，不是想突破就突破
- **有特色**：不要完全照搬别人的体系，要有自己的独特之处

### 境界划分设计建议
推荐7-9个大境界，每个大境界分3个小层次（初期/中期/后期或一至九重）：

```
示例体系（修仙流）：
1. 炼气期（1-9层）    ——入门阶段，能使用基础法术
2. 筑基期（初/中/后） ——真正踏入修行，寿元增加
3. 金丹期（初/中/后） ——凝结金丹，质变，可御剑飞行
4. 元婴期（初/中/后） ——元婴离体，战力大增
5. 化神期（初/中/后） ——沟通天地法则
6. 合体期（初/中/后） ——肉身与元婴合一
7. 大乘期（初/中/后） ——接近天仙
8. 渡劫期               ——渡天劫成仙
9. 仙人（后续扩展）     ——进入更高层次的世界
```

**关键原则**：前期境界可以密集（让读者频繁感受到突破的爽感），后期境界拉长（保持稀缺感）。

### 宗门/家族体系
- 宗门等级：小门派→中等宗门→大宗门→圣地→禁地
- 家族等级：普通家族→大家族→世家→古族→远古家族
- 每个等级应有标志性强者（如：大宗门至少有元婴期长老）

### 天地法则
- 天道规则：天劫、因果、气运等超自然法则
- 资源体系：灵石、丹药、法宝的等级对应境界
- 空间层次：凡界→修真界→仙界→更高层面

## 二、经典套路

### 废柴逆袭
- 开局：主角天赋低/被废/家族弃子
- 转机：获得金手指（传承/系统/老爷爷/重生记忆）
- 要点：前期压抑足够，逆袭时才足够爽
- 代表：《斗破苍穹》——萧炎三年之约

### 重生回档
- 开局：主角从巅峰/死亡重生回到起点
- 优势：前世记忆带来的信息差
- 要点：不能完全靠信息差，要有新的变数和挑战
- 代表：《重生之都市修仙》

### 天才少年
- 开局：天赋异禀，但遭遇变故/被针对
- 要点：天才也需要困难，不能一路碾压，"天外有天"
- 代表：《完美世界》——荒

### 大器晚成
- 开局：平凡谨慎，靠积累和运气缓慢成长
- 要点：每一步成长都有坚实的理由，让读者感觉"真实"
- 代表：《凡人修仙传》——韩立

## 三、核心爽点

### 越级战斗
- **设计要点**：越级幅度控制在1-2个小境界，偶尔跨大境界需要特殊条件
- **爽感来源**：旁人的震惊反应 + 对手的不敢置信 + 合理的战斗逻辑
- **注意**：越级不是靠主角"突然爆发"，而是靠技巧、宝物、特殊体质等有铺垫的优势

### 境界突破
- **铺垫**：突破前至少3-5章的积累/寻找突破契机
- **过程**：详细描写突破时的身体变化、天象、灵气涌动
- **反应**：周围人的震惊，旧敌的恐惧，力量对比的变化
- **节奏**：前期3-5章一突破，中期10-15章，后期20-30章

### 获得神器/传承
- 奇遇不能太频繁，否则贬值
- 每次奇遇都应有风险和代价
- 奇遇的价值应与冒险的难度匹配

### 打脸装逼
- 前提：对方先嚣张/看不起主角
- 过程：主角低调展示实力
- 高潮：对方表情由轻蔑→震惊→恐惧
- 关键：旁观者的反应是打脸爽感的放大器

## 四、节奏特点

### 典型卷结构
```
小副本（10-20章）：秘境探险 / 试炼场
    ↓ 获得资源/突破
宗门内斗（15-25章）：门派争锋 / 排名赛
    ↓ 名扬一方
地域争霸（20-30章）：多势力混战 / 天才聚会
    ↓ 更大的世界
天下大战（25-40章）：终极对决 / 拯救苍生
```

### 地图扩展规律
- 家乡小镇 → 城市 → 王国 → 大陆 → 星域 → 宇宙
- 每次地图扩展，旧地图的"强者"在新地图中变成普通人
- 扩展时机：当前地图的挑战已无法满足主角的成长需求

## 五、常见坑点

| 坑点 | 表现 | 解决方案 |
|------|------|----------|
| 战力崩塌 | 前期元婴期灭城，后期元婴期连打手都不算 | 建立严格的战力标准表 |
| 配角工具化 | 配角只在需要时出现，无独立人格 | 给重要配角独立支线和成长 |
| 地图抛弃 | 离开一个地图后再不回来，旧角色消失 | 安排回访旧地/旧友联络 |
| 金手指贬值 | 前期神器到后期沦为废铁 | 金手指应能随主角成长升级 |
| 女角色花瓶 | 女性角色只会尖叫和被救 | 给女性角色实力和独立性格 |
| 节奏拖沓 | 一个秘境写50章 | 控制每个副本的章节预算 |

## 七、平台策略

### 起点中文网
- 偏好：宏大世界观 + 合理的力量体系 + 稳定的更新
- 读者特征：老读者多，要求逻辑自洽，能接受慢热
- 建议：前30章要立住人设和世界观，不必急于堆爽点
- 字数：日更4000-6000字，单章2000-3000字

### 番茄小说
- 偏好：快节奏 + 密集爽点 + 简单明了的力量体系
- 读者特征：新读者多，耐心有限，前3章定生死
- 建议：第一章就要有冲突和金手指展示
- 字数：日更6000-10000字，单章1500-2500字

> 💡 **核心建议**：玄幻修仙的本质是"成长的快感"。读者代入主角，体验一步步变强的过程。一切设定和情节都应服务于这个核心体验。
