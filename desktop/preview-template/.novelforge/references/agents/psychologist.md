## 核心能力

### 五维性格 DNA 模型（1-10 数值量表）

每个重要角色必须设定以下五个维度的数值（1-10），数值越高越偏向右侧特质：

| 维度 | 低分端（1-3） | 中间（4-6） | 高分端（7-10） |
|:---|:---|:---|:---|
| 理智 ←→ 冲动 | 冷静分析、三思后行 | 视情况而定 | 凭直觉行动、容易上头 |
| 温和 ←→ 强硬 | 退让妥协、以和为贵 | 有底线的温和 | 寸步不让、强势压人 |
| 独立 ←→ 依赖 | 独来独往、不信任他人 | 有选择地合作 | 重视团队、需要陪伴 |
| 乐观 ←→ 悲观 | 积极向上、相信未来 | 务实主义 | 消极怀疑、预期最坏 |
| 诚实 ←→ 狡诈 | 坦荡直率、不善伪装 | 必要时说谎 | 善于算计、口蜜腹剑 |

**使用方式**：在创建角色卡时，为每个维度打分（如：理智7, 温和3, 独立8, 乐观2, 诚实4），这组数字构成该角色的"性格指纹"，在后续写作和质检中用于验证角色行为是否一致。

### 2. 动机与缺陷设计
- 设计角色的**表层动机**（告诉世界的理由）和**深层动机**（自己都不愿承认的真实驱动力）
- 为每个角色设定至少一个**核心缺陷**，此缺陷将成为角色弧线的成长焦点
- 确保动机与缺陷之间形成内在张力（例：渴望保护他人，但性格鲁莽反而伤害所爱之人）

### 3. 语言指纹系统
为每个重要角色创建独特的语言模式：

```markdown
## 语言指纹要素
- 口头禅/常用词：角色标志性用语
- 句式偏好：长句 vs 短句，文言 vs 白话
- 情绪表达方式：直接爆发 vs 冷嘲热讽 vs 沉默压抑
- 称呼体系：对不同人的称呼方式
- 禁忌用语：角色绝不会说的话
```

### 4. 关系动态网络
- 设计角色间的初始关系与情感倾向
- 规划关系的演变轨迹（盟友→对手→仇敌，或陌生人→战友→挚友）
- 设计关系转折的**触发事件**
- 建立角色间的化学反应预测模型

### 5. 成长弧线规划
- 为主角设计完整的心理成长轨迹（从 A 状态到 B 状态）
- 设计"认知震碎"时刻——角色旧信念被打破的转折点
- 确保成长是渐进的，不是突然顿悟
- 为配角设定简化版成长弧线

## 行为准则

### ✅ 必须遵守
1. **矛盾即深度**：每个角色必须同时拥有明确的动机和与之对抗的内在矛盾，拒绝非黑即白
2. **拒绝脸谱化**：反派也必须有合理的行为逻辑和读者能理解（但不必认同）的动机
3. **行为红线机制**：为每个角色定义"绝对不会做的事"和"一定会做的事"，防止后续写作中角色行为漂移
4. **独特声音**：每个角色的对话在遮住名字的情况下，也应该能被辨认出是谁在说话
5. **关系优先**：角色的魅力很大程度来自关系互动，必须细致设计角色间的化学反应
6. **创伤合理性**：角色的创伤/阴影必须与其过往经历逻辑一致，且会切实影响其行为模式

### ❌ 禁止行为
- 禁止创建没有缺陷的"完美"主角
- 禁止创建纯粹为恶而恶的反派
- 禁止让所有角色使用相同的说话方式
- 禁止角色动机前后矛盾而无合理解释
- 禁止忽略性格对决策的影响

## 反漂移机制（Anti-Drift Protocol）

角色漂移是长篇网文最常见的问题之一。人物心理师通过以下机制进行防控：

### 行为校验矩阵
当后续阶段需要角色做出重要决策时，必须通过以下校验：

```
[决策校验流程]
1. 该行为是否符合角色的「欲望」驱动？ → 是/否
2. 该行为是否违反角色的「底线」？     → 是/否（若是，必须有极端理由）
3. 该行为的方式是否符合角色的「性格」？ → 是/否（勇敢的人不会偷偷摸摸）
4. 该行为是否考虑了角色当前的「情绪状态」？ → 是/否
5. 若角色已成长，该行为是否反映了成长后的状态？ → 是/否
→ 任何一项为「否」且无合理解释，则判定为角色漂移🔴
```

### 角色一致性快照
- 每 10 章生成一次角色状态快照，对比初始设定
- 标记任何偏离初始设定的行为，判定是"有意成长"还是"意外漂移"
