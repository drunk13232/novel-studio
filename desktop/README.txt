Novel Studio 2.21.3 Model Control and MCP Preview

启动
解压完整 NovelStudio 文件夹后双击 NovelStudio.exe；保留 _internal。
本包包含运行文件，不包含私人小说、文献、图片或用户凭据。
已有小说工作区由用户自行选择；不要把安装目录当成完整开发源码或小说工作区。
首次启动选择个人数据目录和已有工作区，也可进入独立演示书房。公开发行不附带开发者盘符。
以已有真实作品继续写作时，请选择原来的个人数据目录及已有工作区，不需要迁移或复制。
更换工作区可使用界面已有入口，或 NovelStudio.exe --workspace "已有工作区完整路径"。
手动写作和常用资料管理不要求手动启动 Python 或 Vite。

AI 与开发者说明
AGENTS.md：AI 阅读本包的规则。
AI-DEVELOPMENT.md：给 AI 的接手说明、改动入口与任务模板。
ARCHITECTURE.md：对应源码结构、业务接口和安全边界。
DEVELOPMENT.md：拿到完整源码后的依赖、隔离开发、构建与打包步骤。
运行 ZIP 不附完整源码；同版本独立 NovelStudio-Developer.zip 包含筛选后的源码、锁文件、公开模板和构建说明。修改仍需相应许可。
后续构建会自动附上这四份说明，不复制用户工作区 AGENTS、私稿或运行日志。

界面与排版
设置 → 外观与主题：界面字体、字号、十六套主题（含芳乃／蕾姆本地皮肤）。
设置 → 写作与编辑：正文/阅读字体、字号、行距、宽度与自动保存。
主题：月白纸笺、青岚书房、夜墨星河、琥珀书灯、雾蓝晨光、紫檀夜读。
正文标题旁“字体与排版”进入设置；自定义字体仅使用本机已安装字形，缺少时系统回退；桌面版可刷新本机字体目录，并选用舒适阅读、紧凑编辑或大字阅读。

AI 软件操作与写作
右下角软件助手复用现有受控 Action；Codex 软件操作通过本地 MCP，原小说工作流独立保留。
在设置 → AI 助手中选择仅建议、导航或可撤销草稿；重要操作始终要求确认。
Codex 软件操作、两位角色与 Python Control 共用六十六项注册应用动作；人物菜单仍使用原有本地快捷白名单。已注册能力不代表所有工作台都已完整接入，具体权限、配置与真实回执以运行时目录为准。
普通自定义 API 不天然具备 Codex Skills 或文件权限；写作修改默认生成候选，作者确认。
模型、API、路由、用量和中文帮助在设置中查看。API Key 不以明文进入运行包或备份。
关闭软件后旧待确认操作不自动恢复；重新提出后按当前项目和版本校验。

外部可选依赖
Microsoft Edge WebView2 Runtime：桌面窗口；缺少时使用已有浏览器回退。
Codex CLI、用户自己的登录、已有 Skills/Plugins：可选 AI 工作流。
Pandoc：EPUB3 导出；ComfyUI 与模型/合法 Workflow：可选生图。
Node / Story CLI：可选辅助审计；Windows SAPI5：可选朗读。
第三方依赖许可证位于 _internal/resources/third-party，不代表整份软件源码的授权。

交付边界
本版为 Preview。已执行的本地、浏览器、真实 Codex 与 Windows 验收分别记录，不相互替代。完整语音闭环、真实中文输入法、外部服务稳定性与所有原生场景不宣称全面通过。版本与文件校验清单见 RELEASE-MANIFEST.json；2.21 操作说明见 CHARACTER-PYTHON-CONTROL.md。
部分桌面操作、Windows 输入法、其他电脑环境与长期负载仍需经用户授权单独验证。
没有新增收费请求、真实小说内容或 Git 提交；本版未签名。

世界逻辑实验室
打开小说 → 左侧「世界逻辑实验室」→ 复制模板 → 确认演示假设 → 设置参数与验收 → 确认锁定版本 → 运行。
基础逻辑/公式/量纲/依赖检查离线运行，不需要 Python。AI 设计可用 Codex 登录或自行配置 API，结果是草稿 Proposal，不能自动修改正式设定。
分享模板默认移除原作品参数和来源；报告输出仍可能属于私人资料，请自行检查。

具象化软件助手
顶部「动态人物助手」打开当前人物。点击人物或菜单按钮展开功能；「输入指令 / 查看操作记录」打开原有 AI 软件助手。
先打开作品，才能查询本作品人物、设定和资料。选中正文后可提出选段文学评审或修订候选；需开启选区权限并确认本次操作。
「本角色模型与权限」分别设置芳乃/蕾姆的模型和数据范围。「形象、动作与声音」控制模型、大小和本机合成声音。
动作仅反映真实任务事件；提交评审不等于评审完成。关闭人物界面不会替你取消已经允许执行的任务。
本机私人模型为基础正面网格，手势和原作画风精细度尚不足。公开包不含私人模型、Core、人物原画或角色配音；需自行取得合规本地资源。
完整会话内容当前仅在应用运行期间保持；重启保留各角色配置与操作摘要，不宣称完整聊天回放。
本机验证授权不等于 Live2D SDK 和角色素材公开再分发许可。项目最终开源许可仍由作者决定。

日常写作流程补强
正文 → 本次写作参考：可记住本章参考选择，恢复后仍须重新检查并确认发送。
正文 → 协写候选记录：找回已有候选，原文未变时继续比较，过期或处理后的记录只读。
协写 → 我的写作操作：保存常用要求、模式和候选方向；载入不会自动请求模型。
选中人物/设定名称 → 查选区资料 → 右侧查看资料：复用资料分屏；同名候选由作者选择。
详细步骤见 WRITING-WORKFLOW.md。以上功能不自动修改 Canon、State、Knowledge 或正式 Final。

Codex 连接限制
本轮源码和 EXE 均完成过真实协写；后续复核也多次出现 workspace routing discovery timed out，发生在模型生成前，原因尚未查明。清理宿主环境未能稳定解决，未保留未经证实的 SDK 路由改动，未修改全局登录配置。可保留失败记录、稍后手动重试；不自动切换服务商。手动写作、资料查询和已有候选处理不依赖 AI 连接。

文学内核
正文工具条 → 文学内核：文风、思想、伏笔与叙事逻辑共用作者笔记与原文证据。使用方法见 LITERARY-CORE.md。
AI 解释不等于事实，写作参考需要重新预览和批准 Writer Context；模型生成候选仍通过原有 Diff 确认。

插件入口：设置 → 插件与接入。导入前先预览，安装默认禁用；示例可在界面下载。详见 PLUGINS-AND-INTEGRATIONS.md。
