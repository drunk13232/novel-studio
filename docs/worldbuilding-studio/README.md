# Novel Studio 2.15 AI Worldbuilding Studio Preview

在作品内打开 **世界设定 → AI 世界创作工作台**。原世界百科、实体 ID、人物与章节关联、图片和历史入口保留。离线时仍可编辑蓝图、模板、设定并使用本地世界逻辑实验室。

## 使用

1. **世界蓝图**：记录世界名称、摘要、时代、纪年、自然规则、主要矛盾和模块组合。蓝图是作者构思，不会自动变成 Canon。
2. **模板中心**：常用模板优先显示国家、城市、公司、世界概览、历史、资源和能力体系。完整旧分类仍可展开。复制模板，修改字段，或添加制度、经济、后勤、历史、技术和能力模块。
3. **AI 世界设计师**：输入目标，选择最多六个模板批次和细致程度。可选访谈、深化、选段提取、对抗和历史提案。仅明确勾选的已确认设定、选段和可选蓝图进入模型资料范围。
4. 保存设计稿，选择模型，核对发送范围，再运行一个批次。每批一次调用、最多四个条目；不会自动运行后续批次。百科深度也是有上限的局部批次，不会自动完成整部百科。
5. 核对字段、原文引用、AI 创作建议、条件假设与未知项。可逐项编辑，再保存为待审设定或明确确认正式采用。名字相同不会自动合并。修改既有条目必须指向选定的原 ID，显示原内容并经作者采用；锁定规则仍由 Bible 强制保护。
6. 关联候选单独确认。两端尚未采用时不能建立关联。百科的原有“关联、图片、历史”继续使用同一套服务。
7. 在正式条目中编辑 **Writer 安全摘要与可见范围**，明确确认保存。正文的 **AI 助手 → 参考包 → 已发布的世界设定摘要**可选择它；仍需批准本次上下文包。原始专属字段、秘密、全部百科不会自动进入 Writer。
8. **检验设定 / 反事实**打开原 World Logic Lab，作者核对输入、自然语言到数学规则的映射、冻结标准后运行真实求解。关联线不自动变为经济或政治因果模型。

访谈问题出现后，在左侧填写回答，点击“使用左侧回答新建后续设计稿”。旧稿保留；新稿仍需手动启动。关闭窗口或重启不会自动重启 AI。历史中打开旧稿，可以查看已完成批次并手动恢复未完成批次。

## 模板与版本

字段支持短/长文本、数字、数量单位、自定义纪年、公历日期、枚举、多选、布尔值、标签、文本列表、字段组、单/多实体、图片、规则文本和原文证据。支持说明、分组、顺序、必填、主要字段、AI 可填范围、作者专属、锁定、边界、默认值和条件可见。

默认值只是模板建议，不会自动成为世界事实。长文本可书写 Markdown，但当前不会新增富文本编辑器。嵌套组的高级定义采用受校验 JSON；首层字段使用可视化控件。

保存模板会记录新版本。实体保存时携带完整模板快照；修改模板不改变旧条目的数据。已有字段不能删除、换类型或移除旧选项。不兼容设计应复制为新模板。原条目“更多”中的“预览模板升级”列出新字段，再由作者明确确认升级，已有值保留。

导出模板 JSON 只包含模板、字段和 JSON Schema，不包含实体、作品正文或设计会话。自填默认值和说明可能包含自己的私人信息，分享前仍应检查。导出设计稿则可能包含选定的私人世界设定，不能当作公共模板直接发布。

## 边界

- AI 归类不是事实验证。`SOURCE_QUOTE` 只在原指定资料包含精确引用时通过；引用存在不等于其叙述就是客观真相。
- 未知量保持 null；必填规则在正式采用时检查，草稿允许缺项。作者自定义自然法则由原实验系统表达，模板不执行公式或程序。
- 历史生成先保存 Bible 候选，不写正式 Timeline 或 Chapter Ledger。还没有实现从世界设计一键批量提交历史事件。
- 逻辑与反事实沿用 World Logic Lab，没有增加第二套求解器、世界数据库或分支文件系统。
- 长批次每次最多四项、单稿最多 24 项。尚无自动全百科覆盖、统一世界级模板包、地图编辑或自动历史编年器。
- 界面新增简体中文与英语；其他现有语言使用原回退机制，不代表本轮全部翻译完毕。内置模板内容以中文为主，可由作者编辑。
- Codex 使用已有登录。自定义 Provider 走原模型路由、密钥、授权与费用机制；未配置的真实第三方服务未验收。

## 开发入口

`app/library/bible.py` 为唯一实体/分类写入入口；`world_templates.py` 提供声明式字段约束；`world_studio.py` 负责蓝图、受限设计批次与采用回执。前端复用 `world-bible.tsx`，新视图在 `world-studio.tsx`，上下文仍在 `creative/writing.py`。

文件位于当前作品 `bible/blueprint.json`、`bible/categories.json`、`bible/template-versions/`、`bible/entities/` 和 `bible/designs/`。它们都属于原 Data Center 备份范围。没有数据库迁移。设计记录是提案，不是第二套世界事实。

整体开源许可证与版权主体仍由用户决定。本模块不改变既有许可证决策，也不把用户设定、私人角色素材或模型凭据加入公开包。
