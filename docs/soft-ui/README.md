# Novel Studio 2.18.1 — Soft UI & Visual Refinement Preview

本轮以 2.18.0 为基线，保留 16 套主题与全部创作功能。没有安装新依赖、改变数据库或新增 Agent。

## 视觉体系

共享主题令牌现在区分小型控件、按钮/输入框、卡片、大面板、菜单和弹窗。以月白纸笺为例，依次约为 6、10、16、18、14、22px；其他主题按自身基准变化。留白、水墨与科技主题保持较克制的形状，角色与植物主题更柔和。

用户原有的圆角个性化仍优先；选择 0 时不会被“最低圆角”强制覆盖。颜色、字体和业务设置不迁移。现有主题导入、预览取消、作品独立主题与全局主题继续复用原有机制。

圆角不是唯一变化：卡片边框与阴影分层，欢迎书签、作品封面、章节选中态、标签页、模型控制、聊天消息、世界条目、评分维度、证据卡、菜单、通知与设置浮层采用协调的表面和状态反馈。正文没有纹理、模糊或新增边距，1280×720 下仍保留约 328px 编辑高度。

## 两个实际便利改进

1. 文学评分的“评分历史”改为可展开入口，显示真实记录数量。当前范围/标准表单不再被空历史列挤窄。历史、匿名对比、模型和标准逻辑不变，展开/收起不丢失当前表单输入。
2. 主题画廊搜索会清除输入前后的空格；“ 芳乃 ”可以找到既有主题。移除评分页过时的“2.14 Preview”界面标记，避免误认当前软件版本。

大屏实际打开 AI 侧栏时还发现旧章节标题的宽度上限与居中内边距叠加，导致标题列被挤到 0px、逐字竖排。标题现在使用当前编辑栏宽度，保留原有文本宽度、标题网格和正文编辑器。在 1920×1080 的实际画面中，标题恢复正常横排。窄窗表单对复选框采用独立尺寸，避免它被文字输入框的宽度规则放大。

## 美术资源

新增 `web/frontend/public/themes/quiet-pages.svg`，是本轮绘制的可编辑书页与植物线稿。实际用于书架继续入口与无搜索结果状态，非生成概念图裁切。尺寸 240×180，不使用外部字体、脚本、远端地址或私人作品内容。

资源哈希与字节数记录在 `web/frontend/public/themes/manifest.json`。原有插画、SVG、角色主题、私人芳乃/蕾姆资源保留；私人模型、立绘、语音、Live2D Core 和测试记录不加入公开候选包。整体软件许可证仍由所有者决定。

## 性能与可访问性

- 无新依赖、模型探测、后台轮询或动画引擎。
- 图片按现有 URL 和可见状态加载；新增 SVG 约 1.5KB。
- 阴影用于少数提升层级的卡片和浮层，没有持续大面积模糊、粒子或毛玻璃。
- 动效复用原有强度设置；强度 0、系统减少动画和主题切换期间禁用过渡。
- 复用 Radix 对话框的焦点、Escape 与关闭行为，未重建菜单框架。
- 新样式使用逻辑方向属性，支持现有 RTL。系统 DPI 与浏览器/软件缩放分别记录。

## 参考与复用

- [Radix Radius](https://www.radix-ui.com/themes/docs/theme/radius)：圆角按组件角色分级，而不是把全部控件统一成胶囊。
- [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog)：继续使用已安装组件，保留焦点与键盘行为。
- [Motion Accessibility](https://motion.dev/docs/react-accessibility)：遵守减少动画偏好，不依赖运动传达唯一状态。

实际复用 React、Lucide、Radix、CodeMirror、现有 i18next、主题画廊、设置保存队列和任务系统。没有复制第三方美术或引入新的框架。

## 使用

直接打开现有作品即可使用新视觉。设置 → 外观与主题可以预览、应用、取消或调整圆角；作品独立主题入口保持原位。文学评审 → 文学评分 → 评分历史可以展开记录与对比。

最终启动、三组真实前后对照、包体差异及未完成原生验收见同目录 `DELIVERY-REPORT.md`。没有用浏览器测试宣称真实拼音输入法、系统 DPI 或真实 AI 全面通过。
