# Novel Studio 2.12 Literary Core Preview

文学内核是原有正文、文风库、作者笔记、文学评审、场景导演与世界逻辑实验室的关联视图。它不建立第二份 Canon、人物知识或正文。

## 从正文开始

保存当前章节，在正文 AI 工具条点击 **文学内核**。先选中一段正文再打开，可以把当前选段绑定为证据；没有选段时分析当前章。剧情矩阵的场景详情也能打开此入口，并使用对应场景。

左侧保存作者文学记录和分析历史，中央编辑记录、查看证据和结果。文风 / 思想 / 伏笔 / 叙事逻辑共用人物、章节、场景、剧情线和事件引用。切换或关闭有未保存编辑时会提示。

## 文风：观察与写作要求

- **本地语言统计**复用已有中文分句、引号范围、段落分布和重复表达统计。可选择对照章节，并点击段落或重复表达定位原文。
- 平均句长和对白比例是实际计数，不是文学质量或风格匹配率。引号不一定是现场对白，也不推断发言人。风格变化可能是刻意安排。
- **AI 定向分析**讨论叙事距离、情绪表达、感官、意象、词汇、对白与隐含信息；引用必须在提供的正文中找到，否则报告不保存。
- 从文风报告编辑每行一条的正向要求，确认后保存到**现有文风档案**。可以限定人物对白或当前场景。不会把样本原文、完整分析或其他人物秘密送给 Writer。
- 回到原有 Writer Context 预览并批准；协写和场景导演才会使用这些要求。

## 思想：问题、立场、行动和代价

填写开放的核心问题，关联人物、章节、场景、事件、剧情线与意象。人物立场包含经历、具体选择、代价、反方理由和认识变化。可以选择存在主义、历史唯物主义、伦理冲突、叙事学、社会心理、权力与制度、人物主体性，也可以使用自定义框架。

AI 输出原文观察、条件性风险、信息不足、可能的刻意歧义或文学解释。每种解释保留证据与局限；有依据的反方阅读单独展示。不评判政治立场，不输出思想分数，也不要求每场戏都说理。同一模型的不同解释不是独立评审或科学证据。

## 伏笔：计划与实际出现分开

文学记录从 **PLANNED** 开始。**PLACED / REINFORCED / MISDIRECTED / PARTIAL / RESOLVED** 必须绑定已存在的当前正文；首次强化或回收之前必须有埋设记录。允许多次部分或完整回收，也能选择 **INTENTIONALLY_OPEN / ABANDONED**。虚线表示计划，实线表示有文本证据的作者观察。

可关联既有正式伏笔，不改变其 State 枚举或已提交状态。正文观察仍不是已提交剧情事实。证据保存原文、UTF-16 位置、章节和文件版本；正文变化后明确标为待复核。

**作者隐藏真相**只存作者记录。仅原有 Knowledge 中有效的披露凭证可以授权 Writer，填写凭证 ID 本身不会授予知识。人物怀疑、读者已经读到、作者计划和作者知道，继续由原有角色视图与知识状态区分。模拟读者不读取这些作者记录。

## 逻辑：前提、例外与真实求解

AI 分析动机、知识、资源、因果缺环和合理例外。谎言、倒叙、不可靠叙述和留白不会自动判错。

作者可以登记严格先后、明确因果、尚未形式化的条件或普通关联。确认映射后调用**既有 World Logic Lab / NetworkX**，冻结本次实验版本并保存报告。只有严格先后关系要求 DAG；普通因果反馈环不自动判错，普通关联不等于因果，未形式化条件不参与确定判断。PASS 只覆盖这些前提，不证明整部作品合理。

物理公式、资源、Z3 约束或反事实请使用本页的**现有世界实验室**入口。仍使用已有 SymPy / Pint / Z3 / NetworkX、版本和验收标准，不创建新模拟器。

## 四项成果如何进入写作

1. 保存作者记录，核对原文与适用范围。
2. 在记录下方手动编写**当前 POV 可用的正向要求**。例如：以动作和停顿呈现两人诉求；让选择付出可见代价。
3. 确认选用后，生成原有创作素材。一次最多选 4 项素材与 3 份文风档案，复用当前上下文预算、排除和固定功能。
4. 预览 Writer Context；它不会包含完整作者记录、作者真相、审稿原文或包含秘密的禁止语句。
5. 明确批准后，进入原场景导演或 AI 创作指挥台。模型只生成候选，通过原有 Diff、文件版本校验和作者确认保存。

素材绑定原文版本、POV、场景和文学记录指纹。换章、换 POV 或依据变化后必须重新核对。历史报告不自动重写；AI 建议可保存为现有修订待办或作者文学记录，均不修改正文、Canon、State、Knowledge 或时间线。

## 存储、AI 与限制

- 文学记录、伏笔推进：现有 `metadata/studio/reading.json` 作者笔记。
- 文风要求：现有 `.research/library` 文风档案。
- AI 报告：现有 `reviews/literary`，包含验证过的正文位置、模型和实际方法来源。
- 数学报告：现有 `metadata/world-logic`，可在原实验室继续查看、对比和导出。
- 所有资料按小说隔离，并随原有备份机制保存。没有 AI 连接时，手动记录与本地统计仍可用。
- 分析默认只发当前正文或选段；对照章节、作者记录、人物和 Canon 必须显式选择。云端请求发给所选提供商，沿用原隐私授权。
- 只有可核对的文字证据与声明式关系可自动验证。原文引用真实不等于解释必然正确，语义泄漏检查也不是文学理解的完整替代。作者保留最终判断权。
- 本模块先完成简体中文和英文；其他语言沿用现有英文 / 中文回退，翻译状态仍为 PARTIAL。

## 验收与分发

本版是 Preview。真实 Codex、确定性检查、最终 EXE 的原生 WebView2 交互分别记录，不能相互冒充。物理输入法候选词与全部系统 DPI 仍需人工验收。真实作品不用于测试。私人角色资产、用户资料、凭据与本地验收记录不进入 Windows 或 Developer ZIP。

本轮没有新增运行时依赖，没有更换编辑器、AI 调度或求解框架；整体项目许可证与版权主体仍由用户决定。
