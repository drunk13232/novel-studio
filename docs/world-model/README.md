# Novel Studio 2.16 World Model & Memory Preview

在作品的 **世界设定 → 规则与记忆** 中使用。世界规则、来源和历史继续属于原世界百科；不需要第二个数据库。普通写作、手动设定与本地求解无需连接 AI。

## 规则卡

点击“新建规则卡”，先填写名称和一句话描述。分类可自定义；规则可为硬规则或软规则，适用于整个世界、指定对象、历史时期或实验分支。条件、例外、可信状态、起止时间、数学映射和 Writer 摘要按需填写。

正式硬规则、历史确认和 Writer 摘要发布需要勾选作者确认。AI 生成仍先进入设计候选，只有明确采用才进入百科；保存待审稿不会成为 HARD Canon。作者锁和旧版冲突检查仍生效。

国家、城市、公司、科技、魔法和资源模板增加“关联世界规则卡”。老条目的模板快照不自动改动；需要时先预览模板升级。

规则关系区分实际依赖、普通关联、条件性影响、AI 推测和明确优先关系。影响分析只沿作者确认的实际依赖查找路径，普通连线不成为必然因果。优先关系循环保留为未知，不以创建或修改时间决定胜负。

## 原文引用

“原文与引用”复用本作品文献库及原文阅读器，支持 PDF、DOCX、TXT、Markdown、HTML、EPUB、JSON、YAML 和 CSV。

1. 上传后刷新，查看真实解析状态。失败时原文件保留，不伪造正文。
2. 打开原文，选择一个阅读单元并保存精确摘录。
3. 选择规则或普通世界条目，确认绑定摘录。参考资料仍是 Reference，不自动成为 Canon。
4. 可从来源返回原文位置，并查看 VERIFIED、STALE、UNLOCATED、MISSING 或 UNKNOWN 状态。

PDF 使用实际页；DOCX 使用提取段落；Markdown/TXT 使用行；JSON/YAML 使用结构化路径；CSV 使用行和字段；EPUB 使用书内章节和文本块；HTML 使用净化后的文本块。没有给所有格式伪造页码。

保存的证据包含原文件 SHA-256、阅读单元哈希、摘录位置、来源元数据与用途。元数据编辑不等于原文改变。原文件或提取文本改变时标为过期；候选重新定位不会静默替换旧凭证。旧摘录没有版本凭证时标为 UNKNOWN。

正文引用使用本作品的已保存路径、版本和唯一选段；冲突或多处同文需作者重新核对。引用不改变正文。当前正文绑定面板为高级手动入口，不会自动上传全书。

HTML 只提取文字，不执行脚本或加载远端资源。EPUB 不执行脚本或嵌入对象，不解压到任意文件路径。结构化文件是数据；YAML 不接受可执行标签、锚点或别名。原始 HTML 通过纯文本类型提供，不能成为本机 API 的脚本入口。

扫描 PDF/图片 OCR、联网抓取、BibTeX/RIS 与 CSL 格式化不是本轮完整交付；CSL JSON 可按普通 JSON 阅读和引用，但不能声称具有 CSL 排版引擎。URL 可保存为来源元数据，不自动访问需认证网站。

## 世界记忆与历史

按关键词或实体查询已有 FTS 索引和当前百科。草稿与未采用 AI 设计和正式资料分开显示；近期设计稿搜索有明确覆盖上限。自然语言涉及过去但未给时间时，要求补充边界，不从最新状态猜测。

选择条目并添加“历史时期”：指定时间范围、独立的时期事实和可选安全摘要，再由作者确认。此数据保存在原 `Entity.periods` 中，是作者明确记录的历史设定，不是第二套已提交剧情 State。没有记录的字段保持未知，不从当前字段补齐。多个确认时期重叠时返回冲突。

时间范围含起点、不含终点。公历日期和精确时刻不混用；精确时刻需要时区。架空纪年使用相同坐标名称和数值序号，保留原文字说明，不自动与公历换算。

人物按章知识查询直接复用 2.14 的 Ledger/原始 Proposed 只读投影，不复制投影器。没有历史凭证时不会用今天状态代替过去。大型已提交长篇首次完整投影仍可能较慢；本轮世界时期查询不强制触发全书投影。

点击“交给 AI 设计师解释”，只建立含所选来源和时间边界的查询设计稿。仍需选择模型并确认发送；记忆模式在执行层禁止生成新设定条目。

## 规则推演与反事实

选择最多八张正式规则，填写适用对象和故事时间，并核对条件与例外。先预览“自然语言 → 数学约束 → 规则来源”的映射，明确确认后保存为原 World Logic Lab 的实验草稿。

然后在原实验室确认并冻结标准，运行 Z3 或 SymPy/Pint。数学结果、冲突约束、证据与局限沿用现有报告。软规则作为人工定性条件，不强制转成绝对约束。缺少模型、范围或前提会保持 INCONCLUSIVE；SAT 不等于证明整个世界合理。

规则含有历史时期时，不用当前数学字段代替过去的模型。需要作者为目标时期明确建立对应规则版本与模型；未补齐前保持信息不足。当前版本没有从自然语言历史自动恢复数学模型。

反事实直接复制冻结实验，修改声明的输入，保留 Baseline。可用 Scenario A/B 与现有结果对比。不同阈值会标出；实验输出不会写进 Canon、State、Knowledge、正式时间线或正文。已有 OR-Tools 排程继续在原实验室使用；本轮没有增加 SimPy 或新的社会预测引擎。

## 与写作联动

只有正式条目的作者发布摘要能进入 Writer 参考包。硬软性质随参考保留；仍需预览并批准本次上下文。未确认草案、实验分支、隐藏字段、其他作品资料不会自动加入。

有历史时期时只能采用匹配、已确认并发布的该时期摘要；范围未知、冲突或尚无安全摘要时拒绝使用最新版本代替。实体适用规则需当前 POV 或选定实体匹配。架空纪年没有自动转换到既有写作时间口径。

场景导演与创作指挥台继续使用原模型路由和上下文批准机制，不另建 Agent。AI 世界设计师可以使用明确选定的、尚未过期的文献摘录提出规则草案，原文不会自动成为小说事实。

## 保存与开源边界

规则仍在 `bible/entities/`，模板仍在 `bible/categories.json`，历史时期属于实体，引用仍在 `.research/library/notes/`，提案仍在 `bible/designs/`，实验与报告仍在原实验目录。现有 Data Center 和历史版本保留这些内容。

没有数据库迁移、新模型服务或新增第三方依赖。个人设定、文献、实验、凭据、私有角色素材与检查目录不进入公开候选。整体项目许可证和版权主体继续由作者确认。
