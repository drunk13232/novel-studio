# Novel Studio — Visual Renaissance & Theme Expansion

## 使用主题画廊

打开 **设置 → 外观与主题**。可以搜索名称或风格、筛选明暗、选择分类，或收藏常用主题。点击主题可立即试用；“应用主题”后交由原有设置服务保存，“取消预览”或关闭设置恢复原外观。主题之间不改变保存按钮、导航逻辑或正文内容。

“查看实际组件大预览”展示软件相同语义 Token 和共享组件的排版示例，不代表任何作品已完成评分。没有为缩略图运行模型或完整编辑器。

## 个性化

展开“个性化当前主题”，可调整名称、强调色、文字和页面背景、圆角、装饰/纹理/动效强度与组件密度。预览后应用即可保存在当前主题下，也可导入/导出非敏感 JSON。文字与页面对比不足时会阻止应用，可恢复原始设计。

标题使用主题的本地字体回退方案。正文字体、字号、行距和界面字体继续使用你原有的设置，在本页下方或“写作与编辑”中调整。不在线下载字体，不将 Windows 字体打包。

系统减少动画设置、原有动效关闭、纯净写作模式和专注模式继续生效。主题切换没有持续背景动画。

## 资源与开发

- `web/frontend/src/themes.ts`：主题目录与 Token 映射。
- `web/frontend/src/theme-gallery.tsx`：预览、收藏、自定义及导入导出。
- `web/frontend/src/visual-renaissance.css`：公共组件精修与不同视觉家族。
- `web/frontend/public/themes/`：压缩插画、可编辑 SVG、Schema 与哈希清单。
- `docs/visual-renaissance/art-source/`：6 幅本轮生成的原始 PNG。
- `generation.json`：可复用的生成提示词与来源。
- `TECHNICAL-DECISIONS.md`：实际参考方案、版本、许可与取舍。
- `ASSETS.md`：资源使用和分发边界。

新增界面完成简体中文和英文，其余现有语言明确回退，不计作翻译完成。RTL、缩放和原生桌面证据以最终交付报告为准。

本轮不修改作品、Canon、State、Knowledge、API Key 或 Codex 全局配置；不改变项目整体许可证或私人角色资源的许可。开发证据在 `private-checks/`，不进入发行包。
