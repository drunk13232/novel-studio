# AI 写作（2.10.3 定向深化）

在现有正文工具条展开「本次写作参考」「AI 场景导演」「写后事实提取」。选中正文仍使用原来的协写工具与 Monaco Diff；正文编辑器、版本保护和四种创作模式保持原有机制。

1. 保存正在写的版本，打开本次参考。可选 POV 和带时区的故事时间；按已提交章节与知识获得凭证筛选。缺失历史保持未知，不用当前伤势或位置倒推过去。
2. 查看实际片段，增加当前作品已启用的文献、确认文风、前文章节或检索词。可以排除、固定并限制字符预算。研究、计划、人物认知、原文和正式事实分别标明。查看完整来源属于作者视图，不会把完整文件发给 Writer。
3. 检查自由文本与知识边界后，点击「已检查，确认本次可发送参考」。确认绑定当前版本、选择、参考与状态哈希；任何相关变化要求重新确认。自动过滤不是中文语义审查的替代品。
4. 用一句话要求场景方案，可选择二或三种。采用、组合、编辑节拍，再明确确认生成段落候选。段落可复制或保留灵感，不自动写入正文。
5. 选区协写可选一至三种候选与不同方向，包含有限前后文和同一已确认参考。Diff 中可自行编辑、逐段接受或拒绝，也可保存灵感。正文变化后旧候选拒绝覆盖；Final 继续另存修订稿。
6. 完成现有中文校对与逻辑审核后，提取本章实际原文事实。候选区分明确叙述、人物声称、角色认知、AI 推测、待确认设定。逐项定位、编辑、确认或拒绝，然后保存审阅。
7. 只有候选对应同版且具有效语义 Final witness 的正文，才可送交原有 Memory Keeper。仍须 Proposed Diff、语义审查、Validation 与作者独立 State Commit。缺少门禁时保存候选并说明原因；没有额外的快捷 State 写入接口。下一章只读取正式提交的状态。

## 复用与运行边界

- Context Builder 的知识凭证与 Writer view 投影在既有只读 State 适配层扩展；不复制知识数据库。
- Provider 任务分配增加 scene_design / cowrite / fact_extract，分别回退到原有 outline / polish / review 设置。作者可分别选择模型；不会自动跨服务商回退。
- 继续使用现有 TaskManager、受限 Codex 文本会话或自定义 API、StudioTools Diff、历史检查点、便笺与 Memory Keeper。
- 新面板随正文懒加载，只有主动打开或提交时读取参考或调用 AI；没有新的轮询扫描服务、数据库迁移或依赖。
- 简体中文与英文文案接入 i18next；其他语言采用现有回退，没有伪造翻译覆盖率。
- 自动筛选与精确秘密匹配不是完整语义证明；作者需检查 Writer 参考。无客观分数证明文学质量。
