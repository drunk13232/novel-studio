# 三大创作空间联动

本轮基于 2.10.3 增量完善。所有状态、正文、模型调用、人物、实验、版本和 Diff 都继续使用原有服务，没有增加另一套 Agent 或小说数据库。

## 从正文开始

1. 打开章稿并保存。选择当前 POV，打开“本次写作参考”，核对人物、已提交知识、前文和明确选择的参考。
2. 点击“从本章进入世界实验室”。当前选段（未选择时为章尾）会作为公开情景起点；人物行为、分支对话和 World Logic Lab 使用原有系统。
3. 未提交章节的角色快照只使用此前已提交的知识。界面标出截止章，不倒推历史、不授予未来知识。
4. 从实际人物方案、选中模拟片段、已保存数学报告或 AI 规则建议中选择“带回写作”。保存位置是原有作者工作台的灵感笔记；素材带有来源、分支、选项、原始正文版本和条件性标记，始终不是 Canon。
5. 可在“推演写作素材”修改 Writer-safe 摘要。一次编辑一份，先保存后刷新。选入参考包后必须重新检查并批准；更改素材会使旧批准失效。隐藏真相被检测到时整份素材拒绝进入 Writer，而不通过禁止性语句再次泄漏。
6. 在原有 AI 场景导演生成方案，选择“采用此方案并交给指挥台”。指挥台绑定该方案、章稿版本和作者所选选项，原始方案仍是计划。
7. 选择执行模型。导演模式由 Codex 读取真实方法正文制订任务书，用户确认后由所选模型生成。快速模式仍直接调用执行模型，不额外强制规划。未配置 DeepSeek 时不能宣称已验证 DeepSeek。
8. 执行时可暂停后续调度、中断当前请求并保存新指令，保留已收到文本。修改要求、任务书或执行模型后再继续；已中断网络请求不假装无损续传。
9. 候选进入原有 Monaco Diff，作者接受前正文不改变。旧版本、已处理候选和来源变化继续由原有 Hash/CAS 保护。
10. “本章校审与修订”直接嵌入现有文学评审中心，可以定位证据和打开修订候选，无需丢失当前正文。Final 和 Memory Commit 仍走原流程，推演不能直接提交 State。

## 实际专业方法

保留现有上下文、场景、人物、对白、文风、连续性、文学方法。选择的方法正文与 SHA-256 进入导演请求，任务书和记录可追溯。
资料研究方法只在本机实际安装时显示可用，读取现有安装文件，不复制个人插件缓存进公开包。方法可协助研究规划和整理已提供资料；受限导演调用不因此获得任意网页、Shell 或文件权限。

## ComfyUI：现有接口

“场景视觉参考”将明确选择的选段送入现有 Image Studio。沿用本地服务配置、工作流映射、确认提交、队列、取消和图库。只在存在运行任务时轮询图像队列。切换视觉参考标签保留未保存的工作流和服务地址输入；关闭含未保存工作流的窗口时要求确认。不会自动启动 ComfyUI，不会发送全书资料。没有工作流或服务离线时明确说明，写作不受影响。

## Blender：小型外部工具接口

- 配置本机程序和可信 .blend 模板，明确确认后保存至项目原有偏好记录；程序或模板哈希变化需重新确认。
- 场景、镜头、人物形象和对白参考可独立导出为 JSON，引用当前选段及版本。它是供作者使用的 sidecar，不会自动改造 Blender 场景。
- “打开模板”使用固定参数 `--factory-startup --disable-autoexec`。只报告实际程序启动，不假称渲染完成。
- 选择“渲染现有第 1 帧”复用原有 TaskManager：固定 CLI、最多 2 线程、110 秒上限、日志与结果大小限制、可取消。实际 PNG 使用原有图片导入服务保存。
- 模板加载在 `--render-output`、`--render-format` 和 `--render-frame` 之前，避免模板覆盖输出参数。
- 自动脚本关闭不是完整 OS 沙盒；仅使用作者明确确认的可信本地程序和模板。不提供任意 Python、Shell、SQL、脚本或动态安装入口，不自动下载 Blender。
- 没安装 Blender 时仍可导出场景资料，打开及渲染保持未配置。当前版本不实现自动建模、分镜视频剪辑或模板 Python 注入。

技术依据：[ComfyUI 官方服务路由](https://docs.comfy.org/development/comfyui-server/comms_routes)、[Blender 官方命令行参数](https://docs.blender.org/manual/en/4.4/advanced/command_line/arguments.html)。

## 数据与性能边界

新增素材仍是原有作者笔记，SQLite 和正式小说格式不迁移。所有自动计算与模拟都不改 Final、Canon、State、Knowledge。来源版本不匹配时禁止回传或接受。
角色工作台、求解实验、文学评审和图像界面均通过现有 React.lazy 按需加载。私人角色素材、实验记录、小说、凭据与插件缓存不进入开发源码或公开 Windows ZIP。
新增界面提供中文和英文，其他语言明确回退，不宣称新增文案已完成 26 语言翻译。

实际验证、最终包路径与尚未完成项见同目录 DELIVERY.md。
