# Novel Studio v2.24.0 Custom Workflows Preview — draft release notes

This is a local candidate for the intended `drunk13232/novel-studio` repository. It is not a published Release and is not a claim of comprehensive stability.

## Added and improved

- Editable project-local My Workflows in the existing World Studio and Creative Director: ordered steps, checkpoints, concrete models, scoped sources and per-request settings.
- Reusable world/chapter templates, data-only JSON exchange, version history, bounded execution and recoverable pending results.
- World-first creation without required placeholder cast, plot or prose.
- Existing local writing tools: honest saved-event dashboard, focus tools, guarded global replacement, clue board, narrative curves, simulated readers, maps, print preview, chapter alternatives and offline audio.
- Formal Apache-2.0 license, drunk13232 attribution and intended private GitHub vulnerability reporting. Third-party and user-created works retain their own rights.

## Distribution

Public source ZIP has no Git history or installed development environments. Universal Windows Setup defaults to the current user's LocalAppData data folder; portable Preview ZIP remains available. No private manuscripts, credentials, character models, proprietary Cubism Core or voice assets are included. External Codex/Skills, optional services and Windows runtimes are separate requirements.

## Verification and limits

Use the matching artifact-side AUDIT.md, VERIFICATION.json and SHA256SUMS.txt. Full native IME/DPI, external model quality, optional voices and long-term usage are not comprehensively verified. Local/mock tests are not real remote-AI acceptance. Hosted CI and private vulnerability reporting cannot be claimed active before the repository exists.

SHA-256 values are supplied next to the final candidates; do not substitute hashes from personal/older packages. No automatic upgrade or formal author-content adoption occurs.
