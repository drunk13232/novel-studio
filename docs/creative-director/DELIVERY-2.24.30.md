## Safety

A rework proposal binds the project, task, current candidate, source revision, context, review digest, goal, plan, directions and exact UTF-16 range. Changing these invalidates it. Approval fixes the instruction; execution is a separate explicit action. The dispatcher revalidates it immediately before queuing. Scope outside the target is preserved. Review text and hidden Author data do not become Writer inputs.

No global Codex configuration, real novel, Canon, State or Knowledge is intentionally modified. Existing releases are retained; no automatic commit, publication or shortcut update is part of this delivery.
