## Older source-archive incident

A baseline script bound its intended output path to variable p, then reused p
inside an assignment expression while enumerating old release artifacts. Its
final write therefore overwrote the original 2.21.7 Developer ZIP with the hash
record. This was an implementation error in this pass, not a damaged original
release or a user-data migration.

The record was recovered into private checks and removed from the release
folder so that private file paths cannot be mistaken for a public source ZIP.
No original copy was found in the authorized workspace. The original archive
cannot be claimed restored or hash-identical. The historical checksum remains;
the unavailable artifact is explained in that version's source notice.

All 2,950 author files and global Codex configuration match the captured baseline.
The other 11 protected earlier artifacts, including every EXE and Windows ZIP,
are unchanged. The new release provides a complete new curated source archive;
it must not be mislabeled as a recovered 2.21.7 artifact.
