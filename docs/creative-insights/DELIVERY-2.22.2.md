# Novel Studio 2.22.2 · Narrative Insights Preview

RESULT: PARTIAL. This release strengthens the existing narrative curves and
simulated reader panels. It introduces no dependency, migration, model engine,
paid call, or new manuscript authority. Other creative tools are retained.

## A — emotion and tension curves

- Explicit local analysis, exact excerpts and revision-bound evidence retain the
  existing rough lexical/dialogue method. Scores are not AI literary judgments.
- Book, character-mention and source-verified plotline overlays are comparable;
  author corrections and notes take precedence only for the matching revision.
- Per-series cache hashes preserve unaffected book points when overlays change.
  Hashes are computed once per series rather than once per chapter/point.
- Known/unknown coverage is visible. Missing prose and absent evidence remain
  unknown; unwritten plans cannot be assigned measured scores.
- Flat stretches require consecutive known scores strictly below the threshold.
  They are reminders rather than defects. Anthologies open their member works.

## B — fictional reader profiles

- Existing project-local profile persistence, selected Provider routing, exact
  range/model/budget approval, bounded chunks, history and comparison are reused.
- Persona summaries now require source-verified summary evidence. Unsupported
  reactions, quotations and findings are withheld rather than shown as facts.
  Any unsupported required anchor invalidates its whole reaction.
- Newly completed persona reports are filtered before saving; old files receive
  a filtered read view without rewriting history or renumbering issue decisions.
  Ordinary literary reviews are unaffected. Subjective opinions remain opinions.
- The interface explains withheld evidence and insufficient summaries. Verified
  excerpts use the existing guarded chapter/selection navigation callback.
- No selected Provider is silently replaced and no inference starts on page open.
  Cancelled/failed calls require explicit retry within the approved budget.

## Limits and author data

Native Windows clicks/IME and real remote reader-model quality were NOT RUN.
No personal manuscript is sent to AI. Real model acceptance needs the author's
chosen service and explicit source/cost approval. A model that omits evidence
can legitimately leave no visible judgment. This is safer than inventing one.
The local curve method cannot infer complex literary emotion or character intent.
The 500-chapter metadata index still takes seconds in this sample; this release
makes no instant-response guarantee for large projects.

All writes used isolated projects. Canon, State, Knowledge, Timeline and prose
are read-only to A/B. Metadata and reader history travel through existing backups.
Old packages are retained. No desktop shortcut change, Git commit/push, public
release or global Codex configuration change is part of this delivery.

## Use

Open the existing emotion curve / virtual-reader entry in the creative review
workspace. Select chapters, analyze locally, click evidence and optionally save
author corrections. For readers, create profiles, select chapters and model,
preview and approve the exact range/budget, then explicitly run a reading.
Compare profiles within the same displayed chunk; reopen history without replay.
