# Novel Studio 2.18.0 — Autonomous Product & Art Evolution Preview

本轮基线为 2.17.0。沿用 16 套主题、编辑器、任务系统和全部业务功能。

## 从书架直接继续

书架欢迎区显示上次作品与实际继续章节。点击即可恢复到既有正文工作区。
作品卡改为封面与资料并排；未完成访谈折叠收纳，原有入口仍在。
搜索支持忽略前后空格与英文大小写，没有匹配时可清除筛选。

## 写作导航与全部创作工具

左侧可在“写作导航”和“完整导航”之间切换，选择按作品保存在原有工作区偏好中。
未设置过该选项的作品先使用写作导航；明确保存过完整布局的作品仍使用完整布局。

常用入口保留正文、构思或大纲、人物、世界和文献。其余工具从“全部创作工具”按任务查找。
工具目录与 Ctrl+K 共用一份页面清单；目录不搜索私人正文，不请求模型，也不替代现有全文检索。
“评分”“修改历史”“旧稿”等常用词能够定位已有工作台。

章节目录可按标题、数字、补零编号或“第8章”筛选。搜索无结果会给出清除入口。
所有跳转仍经过原有未保存内容保护，导入仍打开原有导入向导。

## 作品独立主题

打开作品 → 设置 → 外观与主题 → 为这部作品单独设置。

此时画廊的主题选择、颜色和装饰个性化仅保存在当前作品的应用偏好中。
返回书架恢复全局主题；打开另一作品采用它自己的设置或全局主题。
字体、字号、正文、AI Provider、模型权限和角色记忆不随主题改变。

选择“跟随全局主题”可关闭覆盖；作品先前调好的个性化仍保留，便于再次开启。
画廊取消预览仍回到当前有效主题。项目不提供未经记录的“上次项目主题”历史。
主题导入导出继续采用既有 schema_version=1 的白名单格式，不支持脚本和任意资源地址。

## 数据与兼容

没有数据库迁移或新配置服务。只扩展原有 Preferences.workspaces 的两个可选字段：

```json
{
  "appearance": "ink",
  "appearance_customizations": {
    "ink": { "decoration": 30, "motion": 0 }
  }
}
```

这些字段属于应用工作区偏好，不能放进 project.yaml 或 Canon。
后端校验项目权限、16 个主题 ID、个性化字段与范围。项目备份只携带该项目的工作区偏好。
旧项目不需要变更。旧版不认识新增个性化，回退前可保留应用偏好备份。

## 美术与性能

- 保留现有六幅原创 WebP 和 16 套主题；本轮没有靠增加配色数量扩充主题。
- 新增可编辑 desk-signet.svg，作为书架继续入口的低对比书页印记。
- 精修章节书页标题、资料卡、人物选择状态、工具目录和主题作用域卡。
- 插画不进入正文底图；不增加常驻动画、AI 探测或后台扫描。
- 未添加依赖、字体文件、付费素材、Live2D Core 或角色资源。

原创 SVG 源稿即 web/frontend/public/themes/desk-signet.svg。资源哈希在同目录 manifest.json。
已有原始插画继续保留在 docs/visual-renaissance/art-source，来源说明与生成记录保持。
软件最终开源许可证、版权主体及私人角色素材的分发许可仍由所有者确认。

## 实现参考

参考 [VS Code 的可定制布局](https://code.visualstudio.com/docs/configure/custom-layout)：让常用编辑空间稳定，低频工具按需展开。
导航采用普通按钮与折叠分组，参考 [WAI-ARIA Disclosure](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)，没有将页面导航伪装为复杂 ARIA 菜单。
实际复用 React、Radix Dialog、Lucide、CodeMirror、cmdk、既有主题和设置保存队列。
没有复制第三方商业界面、安装重叠组件框架或扩大 AI/MCP 权限。

## 修复语言切换

实测发现：部分语言缺少六个后续工作台翻译文件，旧预加载逻辑因此拒绝整个语言切换。
现在复用 i18next 官方回退机制：核心 common/navigation 资源可用时允许切换，可选工作台继续明确回退英语或中文；核心资源失败时仍保留当前可用语言。
没有复制英语来伪造其他语言的翻译覆盖率。参考 https://www.i18next.com/principles/fallback 。
