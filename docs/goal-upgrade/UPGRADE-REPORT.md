# NOVEL STUDIO GOAL-DRIVEN UPGRADE

RESULT: PARTIAL — 2.10.0 Goal-Driven Creative Preview delivered; native interactive acceptance remains unverified.

## Research

Inspected actual SillyTavern, RisuAI, Promptfoo, LangGraph and Z3 source/docs. Decision record: TECHNICAL-DECISIONS.md. Reused existing AICenter/keyring/Codex SDK/TaskManager, Pydantic, project metadata/checkpoints, ReviewerReport, Monaco Diff, library and World Logic Lab. No new dependency, Agent framework, gateway, runtime service or editor was installed. Copyleft source was retained only in excluded private research evidence, not copied into the public application. Final project license/rights remain the user's decision.

## Multi-AI

Added task groups for actor dialogue, memory, behavior, world design/challenge/explanation and four literary review families. Global, project-task and request/actor overrides use the existing provider registry. Responses/Chat output metadata records observed model when returned. Unsupported parameters warn or fail rather than silently using invalid settings. API budgets support notification or opt-in blocking, with unknown prices/output limits treated explicitly. No automatic cross-provider fallback. Existing streaming, cancellation, provider notices and secure credentials are retained.

## Roleplay

Existing characters, JSON card v2/v3 subset, user Persona, up to eight NPC identities/four replies per turn, scene time/place/chapter and audience-filtered lore. Each actor receives its own evidence-backed view. Author notes, unknown truth and other NPC private profiles are excluded. Reader/author/temporary information is distinct; absent historical suspicion wording is UNKNOWN. Imported scripts/system prompts/extensions cannot become tools.

Durable immutable dialogue nodes, edited/regenerated branches, counterfactual scenes, bounded context, author-confirmed personal memories and saved AI memory proposals. Existing history/checkpoints/backup are used. Chosen dialogue becomes inspiration/scene/chapter material only. Short stories use independent revisions; anthologies do not receive invented prose chapters.

## World Simulation

Conditional behavior alternatives include reasons, premises, consequences and uncertainty. Separate design, challenge and explanation routes use the existing lab. Baseline/scenario comparison preserves original conditions. Inputs/acceptance remain versioned and frozen. Invalid AI expressions are retained as editable proposals, never run or automatically repaired into a PASS. Real mathematics remains in the existing Z3/NetworkX/SymPy/Pint/OR-Tools engines. No numeric social forecasting is advertised.

## AI Review

Twelve dimensions: structure, character, dialogue, pacing, suspense, motivation, causality, world, POV/knowledge, style, repetition and reader. Uses existing Reviewer contracts/specialist technique references; this does not claim every external Skill CLI was executed. Author chooses model, criteria and specific context. Reader mode excludes Author context. Quotes must bind actual source text; ambiguous locations remain visible. Unsupported evidence cannot automatically produce a candidate.

Reports/decisions/todos persist. Comparisons require the same source version and criteria; same observed model/different roles are labelled and never called independent consensus. Current comparison does not freeze every optional reference/character context, so it remains a descriptive aid rather than a controlled model benchmark. Safe candidates use the existing selection service and Monaco Diff. Reject leaves prose unchanged; protected Final acceptance creates an independent revision.

## Integration

Character toolbar opens roleplay. Selected dialogue enters existing workbench material and editor. Behavior questions transfer to existing World Logic Lab. Prose toolbar opens evidence review and existing Diff. References/styles use explicit bounded selections. Three scoped software Actions were registered: list_roleplay_sessions, create_roleplay_session, start_literary_review. The existing Codex MCP whitelist was not expanded; the new actions' full assistant interaction was not freshly certified.

## Remaining Problems

1. Native interaction and normal exit remain unverified because capture did not match the selected window.
2. Codex latency and occasional routing-discovery failures remain external/runtime limitations; no automatic paid retry/fallback is added.
3. Secret-string checks cannot prove resistance to all paraphrases or hidden implications; imported wording and disclosures need author review.
4. Card compatibility is JSON-only/subset; no PNG cards or all tavern plugins. Real long-chat quality and other providers need user acceptance.
5. New UI's other 24 languages fall back; comparisons do not lock every optional context selection. Assistant action registration is not an end-to-end claim for new Codex MCP tools.

## Final Assessment

Core workflows are connected and delivered as an Enhanced Creative Preview: author-driven writing, separate NPC views, persistent simulated memory/branches, actual mathematics and evidence-to-Diff review. This version is ready for user acceptance, not a declaration of complete desktop stability or universal semantic correctness. No further version development was started.
