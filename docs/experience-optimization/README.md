# Novel Studio 2.16.2 — 日常体验优化

本补丁从 2.16.1 的实际写作与 AI 配置流程中修复高频摩擦，没有新增依赖、数据库、Agent 或作品文件格式。

## 日常写作

书架上的“继续写作”使用作品内仍有效的最近编辑位置，其次使用最近打开的正文；不存在时采用已有章节信息中的最近修改稿。书架显示与打开目标使用同一结果。此入口直接进入正文，同时保留原有工作区标签。普通应用重启仍按原设置恢复工作区。

正文只保留一组章节导航。“本次写作参考”“AI 场景导演”“文学内核”保持就近可用；指挥台、校审、世界推演、素材、事实提取与候选历史集中在“更多写作工具”。所有原功能继续调用原业务流程，打开工具菜单不会调用模型。原文关联、章节关联在顶部“创作工具”中。

保留原有自动保存、草稿恢复、版本冲突、POV 知识过滤、来源确认和 Proposal / Diff 流程。工具菜单不会自动确认参考，也不会自动提交 Canon 或 State。

## 模型与上下文

Codex 模型栏可直接点击“读取模型”，无需进入多层设置。读取使用现有登录和 SDK，不要求普通 API Key，不自动开启生成任务。目录仍是目录，不代表模型访问权限已经通过；只有实际完成的推理请求能证明本次访问。

思考选项同时显示可理解的名称和真实参数值，例如“高（high）”。未知档位不会被补造。按需连接和已连接状态保持区分。

预算、输出/推理预留、历史数量和助手回合数复用现有缓冲数字控件。输入到一半时不发送不合法的中间值；结束编辑后校验边界。不支持计价的 Codex 登录模式禁用参考费用上限输入。应用资料预算仍不等于 Codex 服务端完整上下文的硬限制。

## 资源占用

本地朗读面板收起、且没有播放或暂停任务时停止轮询。打开面板或存在播放任务时继续使用原有语音服务和控制，不改变声音来源，也不自动朗读。

升级时语言包随当前发行版本请求，并要求重新验证缓存，避免沿用旧文案而让新按钮持续显示“正在加载”。带内容哈希的大型静态资源仍沿用原有缓存机制。

## 验证与边界

本轮只以原创隔离作品进行写入验证。真实 AI、协议模拟、浏览器交互、Windows 原生交互与文件校验分别记录，最终结果见发行目录 `DELIVERY-REPORT.md`。不把浏览器页面当作原生桌面操作，不把中文 Unicode 插入当作真实拼音输入法验证。

许可、私人角色素材、凭据与作品保护沿用已有发行审计规则。整体开源许可证和版权授权未在本轮重新决定。

技术核实参考：[Codex App Server](https://developers.openai.com/codex/app-server)、本机已安装 SDK，以及项目既有 CodeMirror、Radix Dialog、i18next 与数字输入组件。
