# 先建世界观 / World-first creation

## 使用

1. 书架点击“先建世界观”。
2. 写一句或一段世界设想，例如希望建立怎样的地理、时代、技术或特殊自然规则。
3. 选择已有可用模型，点击“AI 生成世界观草案”。无 AI 时可以手动填写；不强制新配 API Key。
4. 查看世界概览、时代、世界规则、势力、经济和政治候选；不需要填写人物或文学主题。
5. 修改、逐项采用或采用当前显示的候选。生成本身不等于作者确认。
6. 确认创建后进入保存的世界设定。以后需要人物、剧情或详细百科时再使用已有工具。

既有项目的“AI 世界创作工作台”默认选择“先让 AI 搭建世界观”：准备范围并明确确认发送后，生成一份世界概览候选。详细设计模式仍可选择。

## 边界

- 复用现有 Wizard、World Studio、Provider 路由、任务管理和作者采用流程，没有第二套 AI Agent。
- 世界观开局使用 world 任务模型和该入口的模型控制；Codex 或 API 的原有登录及授权机制不变。
- 不加载 Story Architect 的人物、剧情和文学访谈要求；旧故事会话不会被默认发送到世界观请求。
- AI 只能给出世界设定候选；不可靠或缺失数值保持未知，不把新编设定说成确认事实。
- 不自动创建主角、人物卡、长篇故事大纲、正文或已发生事件。
- 现有作品、人物、Canon、State、Knowledge 和 Final 不会因切换入口或生成候选而改写。
- 切换到“构思故事”仍可使用原有完整流程。中英文新增文案齐备，其他语言使用既有回退。

## English quick start

Choose **Build a world first** on the bookshelf, describe your idea and generate a draft using an already configured model. Review and explicitly adopt the proposed world fields, then confirm creation. Characters, plot, prose and literary analysis are optional later steps. Existing projects can use the starter mode in World Studio; advanced world design remains available. No AI connection is required for manual creation.

The world task route, scoped context, draft version checks and explicit author adoption are reused. Generation never automatically changes a manuscript or existing story facts.
