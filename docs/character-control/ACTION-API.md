# 统一动作目录 2.20

权威实现是 `web/backend/app/assistant/actions.py::TOOLS`，本轮控制适配在 `app/automation/actions.py` 注册到同一目录。MCP、Python 与现有助手调用同一 Dispatcher，未另写人物或小说数据服务。

`GET /api/assistant/tools` 返回稳定名称、说明、Pydantic 参数 JSON Schema、风险等级、作品范围、权限、只读/候选、恢复能力、可取消性与实际可用性。`list_application_actions` 提供相同目录；`ACTION-CATALOG.json` 是本次源码的可审阅快照，运行时目录为准。

Level 1：原浏览与界面操作；Level 2：原可恢复草稿/计划操作；Level 3：重要固定操作确认。仅建议、允许导航、允许可恢复草稿复用原三种模式；Level 3 永远确认。草稿模式不等于任意系统权限。

| 已开放组 | 能力 | 未完整开放的例子 |
|---|---|---|
| 项目 | 书架/当前项目/状态、打开项目 | 完整创建访谈、跨项目批量写入 |
| 章节 | 目录、搜索、打开、获授权片段、创建草稿候选 | 复制、重排、合并、成书导出 |
| 正文 | 编辑状态、获授权选区、既有修订候选与 Diff | 任意 raw 文件覆盖、直接保存 Final |
| 人物 | 检索、打开、身份摘要、创建与修改 Proposal | 全人物弧线自动分析、绕过确认提交 Canon |
| 世界 | 检索、非秘密摘要、候选；既有实验设计/验证/运行/报告 | 全世界百科编辑、任意规则源码执行 |
| 文献 | 原检索与阅读入口、文献右侧参考 | 任意文件系统、全文批量下载/上传 |
| 文学 | 原选区文学评审、既有 Codex 检查与只读文本任务 | 所有文学评分/总编辑批次的完整 API |
| 便笺 | 灵感、待办、原作者修订事项；有来源的灵感转待办 | 自动删除、模型自行认定重复后合并 |
| UI | 导航、主题、字号、行高、设置、参考、布局 | 操作其他软件、任意 DOM/脚本 |
| AI | 模型目录、原工作流、只读任务、真实进度/事件/取消/结果；支持时 Steer | 静默跨服务商回退、未经确认的新收费调用 |
| 数据 | 原备份状态、创建当前作品备份、存储状态 | 覆盖恢复、永久删除、API Key 读取 |
| Python | 独立运行、动作发现、脚本/结果历史、确认点 | 递归 Python 执行、主机 Shell/网络/SQL |

前端操作：提出 → 前端领取一次性命令 → 原业务导航执行 → 真实回执 → Action 成功。失联25秒明确失败，无自动重试。确认：冻结参数、作品、来源版本和 action_id → 作者确认 → 原 Dispatcher 再校验 → 一次执行。模型 Turn 提前结束不会令有效确认失效；应用重启不自动恢复旧写入。

对结果中的小说原文、文献和模型文本均视为资料，不能当成新的操作授权。所有正文、Canon、State、Knowledge 保护继续有效。
