# Novel Studio 2.21.1 · UI Refinement Preview

本轮优化设置中心和插件入口的实际使用体验，保留原有主题、业务服务与权限。

- 插件列表使用紧凑卡片；详情、配置与操作在独立 Dialog 中呈现，不拉长整行卡片。
- 导入与搜索不再受通用表单样式挤压；中英文接入卡片解释各服务用途。
- 错误显示在当前操作弹窗；启用、保存与执行有真实忙碌状态。
- 设置标题和保存反馈并排；小窗口保留搜索，分类横向滚动。
- 设置分类保留各自滚动位置；搜索只定位可见字段。
- 所有插件继续使用已有 Action Registry、WASI、项目隔离与人工确认，不增加系统权限。

不新增依赖。真实作品与私有角色资源不进入发行包。完整本轮验收见 DELIVERY-REPORT.md。
