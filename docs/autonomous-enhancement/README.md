# 日常写作流程补强

沿用 Novel Studio 2.10.3 Preview 的编辑器、AI Provider、Writer 隔离、版本历史与资料分屏。本轮没有新增依赖或 Agent。

## 1. 记住本章参考范围
打开正文 →「本次写作参考」→ 调整 POV、故事时间、检索词、人物、文献、文风、预算、固定或排除的来源 → 刷新并检查 →「已检查，确认本次可发送参考」。确认后会记住选择，也可以单独点击「记住本章参考范围」。

重新打开本章会重新构建参考并显示待检查状态。只恢复选择参数，不恢复旧审批；资料变化、缺失或不在当前安全范围时需要重新选择。使用高级区的「恢复已保存范围」「使用默认参考范围」调整。不同作品、文档分别保存，另一窗口改动会触发冲突提示。

## 2. 我的写作操作
打开「协写候选记录」或选中正文显示协写工具 →「要求与文风」填写要求、候选数量与方向 →「我的写作操作」选择操作类型、命名保存。

下次点「载入要求」，检查选区及本次写作参考，再点「按此操作生成候选」。保存或载入模板不会请求模型。模板只保存本作品的模式与正向要求，不保存或切换模型、密钥、上下文审批或文件权限。

## 3. 找回已有协写候选
正文工具栏 →「协写候选记录」。不必重新选区，也不必重新生成。未处理且原文未变化的候选可继续在原 Monaco Diff 中比较、编辑和按块采用；正式 Final 仍走原有另存修订稿及版本保护。

已采用、拒绝或原文版本已变化的记录只能查看、复制和保留灵感，不能覆盖当前正文。实际采用文本与最初生成的其他版本分别保留。历史按文档分页，打开时不调用 AI。

## 4. 从正文查资料并分屏对照
选中人物或设定名称 →「查选区资料」→「右侧查看资料」。复用现有资料侧栏和分栏，正文继续保留在中央。相关章节可用「右侧对照章节」只读打开。

只按现有名称、别名及有效的作者确认锚点匹配；同名或同别名会列出候选供作者选择。未保存的选区只作字面查询。章节提及不等于实际出场、发生事件或角色已知事实。此面板是作者资料查询，不会自动进入 Writer Context，也不会新增正式实体关联。

## 边界与验证
本轮验证使用独立公开演示作品副本，不以测试改动真实作品。保留既有中文校对、文学评审、场景导演、事实提取和 State Commit 门禁。没有通过本轮自动采用任何正式 Canon、State、Knowledge 或真实 Final。

前端新文案提供简体中文和英语，其他语言使用既有回退机制。当前版本仍是 Preview；真实 Windows 拼音输入法、系统 DPI、第三方远端模型和长期负载不属于本轮完整验收范围。实际检查及发行位置见本轮交付记录。

## 已知 Codex 连接限制
本轮源码后端与 Windows EXE 均曾完成真实 Codex 协写，返回两个候选。后续 EXE 复核多次遇到 `workspace routing discovery timed out`，发生在模型生成前；清理宿主环境未能稳定消除问题，来源尚未查明。没有保留未经证实的 SDK 路由修改，也没有改动全局登录、配置或权限。不要把当前 Preview 当作 Codex 连接稳定性已完全通过；发生此错误时保留任务记录、稍后手动重试，或继续手动写作及已有候选处理，不自动切换服务商。普通独立启动曾成功，但不能保证它总能避免此错误。

## 小窗口写作
辅助工具区现在限制展开高度并独立滚动，正文保留最小可操作高度。展开候选记录、操作模板或参考时仍可点击正文；专注模式和原有资料分屏继续使用原布局。
