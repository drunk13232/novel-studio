# Advanced AI Controls（2.16.1 Preview）

此版本扩展既有 AICenter、Provider Adapter、Codex SDK、TaskManager、创建向导、世界设计稿和助手会话。没有第二套聊天数据库，没有增加 Agent 框架或依赖。

## 日常使用

1. 在创建小说 / 一起构思、AI 世界设计师或已有 AI 模型选择器中，直接选择服务商和 **具体 Model ID**。
2. Codex 用户第一次点击“高级控制 → 模型目录 → 读取 Codex 模型目录”。目录来自本机 SDK，不是写死的模型列表，也不保证账号拥有每个模型的访问权限。真实请求回执记录请求模型与返回模型。
3. 选择该模型已确认支持的思考档位。未读取目录或 API 模型没有确认的档位时，仅提供模型默认。API 模型在“设置 → AI 接口”添加、编辑、删除，填写能力依据和经过核实的档位；手动配置不代表真实服务已验证。
4. 打开“上下文”：设置 8K、16K、32K、64K、128K 或自定义 **用户预算**。未知的模型上限显示未知，预算不会扩大模型容量。
5. 在一起构思、世界设计稿与软件助手中点击“查看本次上下文”，可查看真实构建的资料、版本、历史、Skills、固定来源、排除项与裁剪原因。修改来源后重新构建；预览不会调用 AI 或执行工具。
6. 一起构思在发送时重新构建并校验载荷。可以在生成期间编辑设定和下一轮配置。旧结果保留并标记可能过期，不能覆盖生成期间的新编辑。
7. 生成中的模型不会被下一轮设置替换。可等待完成，也可主动停止、保留已生成内容，再明确发送下一轮。不会自动续写或跨服务商回退。

## 历史、来源与预算

- 历史支持最近 N 条、最近 N 轮、按预算、全部可容纳、手动选择和关闭；固定消息优先，原始记录不会因裁剪或切模型而删除。
- 创建向导支持作者摘要、来源范围、摘要版本、讨论记忆候选和创作分支；这些都不是 Canon。可在上下文中查看原始消息及其模型。
- 每个来源可固定、排除、明确加入、调整优先级。类别预算可单独设置。必要任务与固定来源超预算时拒绝请求，不会偷偷移除固定规则。
- 模型上限与用户预算分别保存。无官方 tokenizer 时，应用使用保守 UTF-8 字节估算；这不是官方计费 Token。
- 输出与推理预留仅用于本地容量规划，不保证实际生成规模。API 最大输出字段按模型和协议映射；Codex SDK 没有普通 API 的输出 Token、温度等控制，界面禁用这些字段。
- Codex 自带的内部上下文、内建工具说明和服务端注入不能由资料面板完整观察或精确裁剪。回执分别保留应用资料估算与服务端实际 Usage，**不可把本地资料预算当作 Codex 完整请求的硬 Token 上限**。纯文本胶囊使用精简基础指令，文件与 State 工作流继续使用原隔离机制。
- 请求安全指令、凭据与模型隐藏推理不进入可编辑预览。只显示用户可管理资料、必要任务配置与可公开的容量占用。

## 生效参数与配置优先级

本次覆盖 → 会话 → 当前作品的功能设置 → 功能设置 → 作品默认 → 全局默认 → 模型参数。可保存命名预设，或另存到全局、作品、功能、会话作用域。

请求创建后固定配置；每轮保存 Provider、选定/请求/返回模型、实际参数、上下文版本、来源清单、Usage、首次输出与总耗时。价格未知或 Usage 缺失时费用为未知，不编造精确数字。

API 仅发送确认支持的参数。未知、无效、冲突的参数明确拒绝，不会静默省略推理档位。Chat 使用 `reasoning_effort`，Responses 使用 `reasoning.effort`。DeepSeek 官方端点的思考开关按官方协议映射；思考模式会忽略的温度和惩罚项会被阻止。模型专有采样范围需由元数据或用户核实配置。

不提供任意 extra_body、Header 或脚本注入。Gemini / Claude 原生协议本轮没有新增；已配置的 OpenAI 兼容入口按其声明能力处理，不能宣称等同原生适配。

非幂等生成的自动重试仍为 0。单次参考费用上限要求有效输出上限和价格；不能核对时拒绝启用。不能代替服务商官方账单和费用上限。

## 已有工作台

共享模型选择器提供精确模型、思考、参数、预算和预设，覆盖现有场景导演、协写、角色、评审、评分、逻辑设计和创作指挥入口。导演、执行、评审仍可分别选择。评分预览的模型签名包含控制设置，改变口径后需要重新预览。

创建向导、世界设计稿、具象化/软件助手拥有本轮逐来源预览。其他已有工作台保留原本的 Writer-safe / 资料选择与专用预览；未逐项结构化的任务作为不可拆分的必要任务检查总预算。不能假称所有页面已经拥有相同粒度的来源移除或历史摘要 UI。

软件助手复用已有会话文件，按作品和角色隔离，跨模型展示可见讨论并保留来源。模型与工具内部状态不跨 Provider。选择历史、切换 Provider 仍受现有远端发送授权约束；固定确认 Proposal 与写入权限不随模型变化。确定性快捷操作继续直接走本地 Action。工具规划保留原有非流式模式和操作次数上限。

## 隐私与恢复

配置仍保存在用户数据目录的 `ai-settings.json`；API Key 仍由现有 Keyring / 会话密钥服务保存。创建会话、世界设计和角色讨论沿用各自原有存储。开发者包不含用户配置、作品、测试记录、模型会话或凭据。

关闭重开可恢复保存的配置、可见历史与摘要；不会自动恢复 Codex 任务、写入授权或已过期的确认。

## 验收边界

定向本地测试、真实 Codex、浏览器交互和 Windows 原生交互分别记录。第三方真实 API 没有未经授权调用；本地兼容协议成功不代表远端 DeepSeek / Gemini / Claude 已验证。最终运行结果见发行目录 `DELIVERY-REPORT.md`。
