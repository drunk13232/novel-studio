# 2.10.3 数字输入热修复

修复新建小说目标字数逐位保存导致失焦，以及旧保存回执覆盖新输入。元数据先本地编辑，停顿 800ms 后合并保存；保存退出、切换阶段和启动任务前仍显式保存，失败保留输入并显示错误。

同类修复：封面宽高、PDF 页码、自动保存延迟与备份保留份数可清空并连续输入；输入范围在结束编辑时校正。复用现有表单与保存服务，没有新增依赖或修改小说数据格式。

实际检查：修复前输入 150000 仅留下 1 且失焦；修复后慢保存期间连续输入正常，旧回执不回退，立即退出重开保留最新值，模拟保存失败后仍可编辑并重试。封面、自动保存延迟、备份保留份数和 PDF 第十二页连续输入均在隔离环境检查。此为定向回归，不是整套软件全面验收。

前端生产构建通过。Windows 修复包沿用已有 EXE/后端，只更新前端资源，保留原发行版；私人角色资源、作品、凭据和本机路径不进入可分享 ZIP。
