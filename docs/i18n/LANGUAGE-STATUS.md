The denominator counts logical keys; plural variants count as one key and require the locale's Intl.PluralRules categories. Missing keys are not copied English strings: runtime fallback is exact locale → English → Simplified Chinese. pt-PT never falls back to pt-BR. There are 27 registered namespaces. Advanced dynamic metadata, server diagnostics, component menus and concatenated fragments remain outside complete adaptation.

The daily reliability follow-up adds the 48 new author-workflow keys to each of the other 24 locales (1,152 translated values), including context restoration, local entity lookup, writing actions and read-only candidate history. Earlier writing keys remain on fallback where absent. The creative and quality namespaces use explicit empty catalogs in unfinished locales so runtime fallback does not cause missing-file errors; empty catalogs add zero translated keys.

English and Simplified Chinese have full registered catalogs, but that does not certify all rendered UI. Translation coverage is independent of novel-writing quality, native font shaping, physical IME and Windows system DPI acceptance. No author's manuscript or private knowledge is translated by changing the interface language.
