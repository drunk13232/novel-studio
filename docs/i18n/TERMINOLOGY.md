# Translation terminology

| Stable term | Interface meaning | Simplified Chinese | English reference |
|---|---|---|---|
| Canon | Author-confirmed story facts | 已确认设定 / Canon | Confirmed story facts / Canon |
| State | Committed runtime story state | 已提交剧情状态 / State | Committed story state / State |
| Knowledge State | A character’s evidence-backed knowledge | 人物知识状态 | Character knowledge state |
| Final | Protected final manuscript | 定稿 / Final | Final manuscript / Final |
| Draft | Reversible manuscript draft | 草稿 / Draft | Draft |
| Proposal | Unconfirmed suggestion | 待确认候选 / Proposal | Proposal |
| Writer | Restricted writing role | 写作角色 / Writer | Writer |
| Reviewer | Read-only review role | 审稿角色 / Reviewer | Reviewer |
| Context | Scoped model input | 上下文 / Context | Context |
| Foreshadowing | Clue or future payoff tracking | 伏笔 | Foreshadowing |
| Scene | A narrative scene | 场景 | Scene |
| Volume | A project’s volume | 卷 | Volume |
| Chapter | Stable-ID story chapter | 章 | Chapter |
| Codex / MCP / API | Technical product or protocol identifiers | 保留原名 | Keep original names |

Other-language equivalents are preliminary. Native reviewers should use consistent terms within a locale and explain specialized concepts for ordinary authors. Do not translate stored enums or claims into different machine values.
