# Novel Studio 2.12.1 Literary Evaluation Preview

入口：作品 → 文学评审 → 文学评分。编辑器的章节评审也提供同一入口，可携带当前已保存选区。

1. 选择正文选区、单章、任意多章、连续章号（可按卷）或全书。选择版本后点击“预览范围与调用量”。
2. 勾选所需维度，调整权重、作品目标和高/中/低评分锚点。可保存个人标准的新版本；旧评分保留原标准。默认标准是可修改的辅助配置，并非公认文学量表。
3. 查看真实章节清单、字符数、原文阅读/综合单元和每个模型价格；价格未知不估造费用。确认冻结之后仍不会调用模型。
4. 按“开始 / 继续本批评分”。默认每批最多 4 次模型调用，上限 20 次；不自动把整部长篇全部排入付费请求。暂停或取消后，可从已保存单元继续。失败/中断请求可能已计费，必须明确勾选重试；成功单元不会重复请求。
5. 查看原文证据、得分、优点、不足、另一解释及局限。引用重复时可选择实际位置。正文变化后，旧评分标为过期，禁止继续混入新正文；创建新评分进行版本比较。
6. 有价值的问题可转入既有修订待办，或进入原有评审、正向 Writer-safe 选区候选与 Monaco Diff。作者不采用建议，不影响既有分数。

## 范围和全书覆盖

- 选区默认只发送这段原文。可选作者文学记录必须明确勾选；选区额外记录还需开启额外上下文授权。不会自动装入 Canon、全部人物秘密、文献或未来大纲。
- 单章和自由选择可指定现有正文版本。连续范围/全书每章优先使用 Final；无 Final 时使用目录当前可用正文。预览列出实际版本。计划无正文不当成已写章节。
- 不连续章节明确标出目录中被跳过的中间章节；从未给出的章节不可据此推断剧情连续性。
- 原文按不超过 12,000 Unicode 字符的连续片段完整分解，不丢弃尾部。每个片段都实际提交模型并取得合法、证据校验后的结果才计入处理覆盖。
- 同章多个片段按最多三项一组分层综合，然后各章按同样方法跨章综合。综合不是机械平均章节得分。最终判断使用完整原文阅读证据卡，并非一次把整部长篇塞进一个请求。
- FULL_COVERAGE 表示目标文本全部完成原文阅读；还须完成综合才能获得最终范围分数。空正文、无法读取或任一未处理目标 => PARTIAL_COVERAGE，不显示冒充完整范围的总分。已有章结果可独立查看。
- 覆盖率证明传入和处理了目标原文，不证明模型理解正确、评价客观或文学质量已被认证。

## 得分和证据

八维：语言文风、人物、结构、思想主题、伏笔悬念、叙事逻辑、情感、创新。作者可关闭维度并保存个人标准。

综合分 = Σ(适用维度得分 × 权重) / Σ适用维度权重。N/A 与证据不足使用 null，退出分母；不扣零分。实际参与权重公开。

所有计分维度须有当前处理片段中的真实引文；综合引用只能使用下级已核实并实际提供的证据。无效引文撤回，降低判断确定性；没有有效引文则不计分。位置采用现有 UTF-16 坐标和原文版本。长线结构与主题不可凭短片段确定。

思想评价关注人物经历、价值张力、表达和代价，不评政治立场正确性。创新性不等于偏离传统。客观校对错误仍由既有校审区分，主观评分不升级为 Canon 错误。

## 历史、比较和模型

每次记录锁定原文 SHA-256、标准/权重、范围、方法、顺序、选用作者记录和模型绑定。逐单元保存实际响应模型元数据、耗时与结果；作者批注另行保存。原文快照及结果属于项目私有评审数据，受既有备份覆盖，不进入公开包。

默认单模型；第二模型需明确选定，分别处理相同原文，增加调用量并受原有隐私/预算门禁保护。同一模型重复运行明确不构成独立共识。不同模型也不是科学证明。不自动跨服务商回退。

历史对比提示范围、标准、权重、实际模型或顺序不同。N/A 导致实际参与维度或归一化权重变化时，也会提示综合分不能直接视为质量变化。API 模型的非敏感生成参数与请求配置一并绑定；更改后不能在同一冻结评分中悄悄换用。修订前后正文长度变化本身不构成范围不同。匿名 A/B 仅隐藏对照标签，不声称完成独立盲法实验或模型顺序偏差校正。原文证据可保留文字中的人物名称。

## 资源与限制

沿用现有 AICenter、Codex data-only capsule、TaskManager、项目权限、作者待办与 Diff。没有新增依赖、Agent、数据库或队列。单次上限 2,000 章、2,000 万字符、12,000 处理单元；每批有调用及 600 秒默认运行边界。远端已发送的请求不保证可退款；取消会停止后续调度并丢弃迟到结果。

历史侧栏当前展示最近 200 条评分；原记录保留在项目评审目录。

新增页面接入 i18next，提供简体中文和英语。其他语言回退英语，尚未做新增文案的母语验收。默认评分标准文本为中文，作者可编辑为其他语言；模型按原文语言回应。

Preview 不代表全部历史功能、物理中文输入法、Windows 系统 DPI、所有远端服务或数百章云端评分已完成实机验收。
