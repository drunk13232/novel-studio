# Scoring method and reuse decisions

This extends ReviewCenter, not a new review application or agent. Typed Pydantic output, existing AICenter privacy/budget/model routing, data-only CHECKER adapters, TaskManager, UTF-16 source anchors, author revision todos and guarded Diff are reused.

Rubric construction uses the general principle of explicit criteria, genre/purpose awareness and selecting applicable rows from [CMU Communication Core Values Rubric](https://www.cmu.edu/corecompetencies/communication/resources-and-tools/commcorevaluesrubric/index.html). That educational rubric is not a validated fiction scoring instrument. These original editable defaults are author assistance, not norms or ideology tests.

Hierarchical bounded synthesis follows decomposition patterns in the [OpenAI long-document cookbook](https://github.com/openai/openai-cookbook/blob/main/examples/Summarizing_long_documents.ipynb) and [book summarization research](https://openai.com/index/summarizing-books/). Here every target source is fully read in leaves, exact evidence is verified at each level, and missing coverage suppresses final scores. Summaries alone cannot establish full coverage.

The task DAG and original snapshots are immutable review metadata. Only completed units are reused. Every explicit batch has a request cap; interrupted requests need explicit retry. Provider binding is checked before sending, and current source versions before progressing. A model's output never computes the weighted total, changes the rubric, opens more scope, or edits manuscript/Canon.

Results are not scientific consensus. Different rubrics/models/orders may change judgments. No model is forced to score above 90 or invent differences. Literary ambiguity and missing evidence remain visible. Anonymous historical comparison is not advertised as a blinded validation study.
